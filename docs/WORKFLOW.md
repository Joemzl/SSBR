## 六、关键指标

### 6.1 数据规模

| 指标 | 数值 |
|------|------|
| 官能化样本数 | 68 |
| 解读文档总数 | ~340 (每样本 5 个) |
| 向量维度 | 1536 |
| 覆盖官能团类型 | 羟基、羧基、氨基、环氧基、硅烷、胍基等 |

### 6.2 性能指标

| 指标 | 数值 |
|------|------|
| RAG Hit Rate@5 | 91.7% |
| 向量检索延迟 | ~5ms (HNSW) |
| 单样本问答响应 | ≤5s |
| 综合问答响应 | ≤8s |
| 重排模型大小 | ~1.1GB |

### 6.3 质量保证

| 机制 | 说明 |
|------|------|
| 零幻觉原则 | 所有数值必须可追溯到文献 |
| 数据来源层级 | L1 (表格) > L2 (图面标注) > L3 (曲线估读) |
| 外推边界 | 数据范围外 50% 以内 |
| 置信度标签 | 高/中/低 + 支撑数据点数 |
