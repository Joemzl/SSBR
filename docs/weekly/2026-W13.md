## 六、Bug 修复 (03-25)

### 6.1 综合分析"未知"问题修复

**问题描述**：综合分析回答中出现大量"未知官能团"、"未知作者"等占位符。

**根本原因**：`aggregator.py` 的 `_parse_yaml_front_matter()` 只处理顶层 YAML 字段，未正确解析嵌套的 `functionalization` 对象。

**修复内容**：

1. **`scripts/synthesis/aggregator.py`**
   - 新增 `functionalization` 嵌套字段解析
   - 映射 `core_functional_group_name` → `functional_group`
   - 映射 `degree` → `functionalization_degree`
   - 映射 `reagent` → `reagent`

2. **添加作者提取正则**
   - 从引文格式中提取第一作者：`\*\*引文\*\*[:：]\s*([A-Z][a-z]+ [A-Z])`
   - 从引文中提取年份：`\*\*引文\*\*.*?,\s*(\d{4}),`

**验证结果**：

| 样本 | 修复前 | 修复后 |
|------|--------|--------|
| SSBR-115 | 未知官能团 / - / None | 环氧基 / 13.8 mol % / Yuan J |
| SSBR-069 | 未知官能团 / - / None | 胍基 / 135.25 mmol/kg / Mao Y |
| SSBR-001 | 未知官能团 / - / None | 羟基 / 3.6 wt% / Gao W |

### 6.2 智能问答"未知"问题修复

**问题描述**：智能问答 `answer()` 返回的方案详情中"官能化试剂"和"官能化程度"显示为"未知"，尽管数据.xlsx 和 summary.md 中有完整数据。

**根本原因**：`answer_generator.py` 只传递 `content`（原始 Markdown）给 Prompt 模板，没有使用 `SampleAggregator` 提取结构化元数据。LLM 无法从 YAML front matter 中正确解析嵌套字段。

**修复内容**：

1. **`scripts/answer_generator.py`**
   - 在 `generate()` 方法中集成 `SampleAggregator`
   - 为每个样本提取结构化元数据（functional_group, reagent, degree 等）
   - 将元数据字段添加到 `samples_for_prompt` 字典

2. **`scripts/utils/prompt_templates.py`**
   - 更新 `_format_samples()` 函数
   - 优先使用结构化元数据字段
   - 添加官能化信息表格（试剂、程度）
   - 添加数据来源信息（作者、DOI）

**验证结果**：Prompt 模板现在正确接收并显示元数据：

```
方案 1: 环氧基官能化
| 项目 | 内容 |
|------|------|
| 官能化试剂 | 甲酸 + 过氧化氢 (原位过氧甲酸) |
| 官能化程度 | 13.8 mol % |

数据来源: Yuan J 等人 - DOI: 10.1021/acs.iecr.1c04519
```

### 6.3 Web Demo 数据格式化修复

**问题描述**：Web Demo 的"方案详情"中"官能化试剂"和"官能化程度"仍显示为"未知"。

**根本原因**：`demo/data_formatter.py` 有独立的 YAML 解析逻辑，与 `aggregator.py` 不同步：
1. 检查条件 `"is_functionalized" in func_info` 过于严格（实际 YAML 没有此字段）
2. 使用 `func_info.get("functional_group")` 而非正确的 `core_functional_group_name`

**修复内容**：

**`demo/data_formatter.py`**
- 放宽检查条件：只要 `functionalization` 字典非空即处理
- 添加字段名 fallback：优先 `core_functional_group_name`，备选 `functional_group`

**验证结果**：

```
## 官能化方案
| 项目 | 内容 |
|------|------|
| 官能化试剂 | 甲酸 + 过氧化氢 (原位过氧甲酸) |
| 官能化程度 | 13.8 mol % |
```
