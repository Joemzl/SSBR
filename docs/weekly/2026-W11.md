### 三、数据录入工作流

#### 阶段 1：批量录入（~100 篇文献）

```
PDF 文献 ──▶ Gemini Pro ──▶ Markdown 表格 ──▶ import_metadata.py ──▶ 数据.xlsx
   │            (网页版)        (提取结果)         (自动导入)          (23列)
   │
   └── 使用标准化提示词：other/解析数据的提示词.txt
```

**操作步骤**：
1. 上传 PDF 到 Gemini Pro 网页版
2. 发送提示词，获取 Markdown 表格
3. 粘贴到 `dataset/extracted_data.md`
4. 运行 `python scripts/import_metadata.py --file dataset/extracted_data.md`

#### 阶段 2：SI 数据补充

```
DOI_SI="有" 的样本 ──▶ 下载 SI ──▶ 添加到 Zotero ──▶ AI 提取补充 ──▶ 更新 Excel
```

**适用场景**：苯乙烯含量、乙烯基含量等数据在 SI 中

#### 阶段 3：解读文档生成

```
数据.xlsx 样本 ──▶ Skills 解读 ──▶ 各类解读文档 ──▶ summary.md ──▶ RAG 可用
                    │
                    ├── @ssbr-mechanical-interpretation (力学)
                    ├── @ssbr-dsc-interpretation (热学)
                    ├── @ssbr-nmr-interpretation (核磁)
                    └── @ssbr-tem-interpretation (TEM)
```
