| 上下文精度 | Context Precision | 0.787 | ★★☆ |
| 上下文召回率 | Context Recall | 0.580 | ★★☆ |

上下文召回率（Context Recall）衡量检索结果是否覆盖了回答所需的全部关键信息。在有标准答案（Ground Truth）的 5 个查询中：

| Q10 (试剂选择) | 0.667 | 中等召回 |
| Q12 (微观结构) | 0.570 | 中等召回 |

平均召回率为 0.580，表明系统能够覆盖约 58% 的标准答案所需信息。这一数值受以下因素影响：

1. **知识库规模**：当前 68 个样本的覆盖范围有限
2. **检索深度**：每次查询仅检索 Top-5 样本
3. **问题复杂度**：跨文献综合类问题的信息需求更分散

## 6.3 生成质量分析

### 6.3.1 忠实度指标解读

忠实度（Faithfulness）是 RAGAS 框架中争议较大的指标之一。本系统的忠实度得分为 0.303，需要结合系统特性进行解读。

**忠实度计算原理**：

RAGAS 将生成的回答分解为若干独立声明（claims），然后判断每个声明是否可以从检索上下文中直接推断得出。忠实度定义为：

$$\text{Faithfulness} = \frac{|\text{可从上下文推断的声明}|}{|\text{回答中的全部声明}|}$$

**本系统忠实度偏低的原因分析**：

1. **综合推理型输出**：本系统是"综合推理型 RAG"，输出内容包含三个层次：
   - **第一层（数据引用）**：直接来自检索结果，可验证 ✓
   - **第二层（分析推理）**：基于多样本归纳得出，间接依赖上下文 △
   - **第三层（推荐结论）**：综合判断后给出，超出单一上下文 ✗

2. **结构化输出格式**：推荐卡片中的表格框架、字段标签等格式化内容不属于"可验证声明"，但被计入总声明数

3. **跨文献综合**：当系统从 5 篇文献中综合信息时，某些结论可能需要组合多个上下文才能支持，而 RAGAS 逐一验证的机制难以捕捉这种跨源推理

**图 6-3：RAGAS 评测热力图**

![RAGAS 热力图](../evaluation/figures/ragas_heatmap.png)

*图注：热力图以矩阵形式展示了每个测试查询在各评测指标上的详细得分。颜色从红色（低分）过渡到绿色（高分）。可以观察到 Citation Accuracy 和 Recommendation Completeness 两列全为深绿色（1.0），而 Faithfulness 列颜色较浅，分布在 0.1-0.5 区间。*

- **Faithfulness 列颜色较浅但均匀**：标准差仅 0.129，说明不同问题类型的生成一致性较好

### 6.3.2 回答相关性分析

回答相关性（Answer Relevancy）通过"反向问题生成"方法计算：让 LLM 根据回答内容反向生成可能的问题，然后计算生成问题与原始问题的语义相似度。

综合分析模式的回答相关性为 0.606，处于良好水平。各查询的相关性得分分布如下：

**表 6-5：回答相关性分布**

| 得分区间 | 查询数 | 代表查询 |
|----------|--------|---------|
| 0.7-0.8 | 2 | Q4 (配方设计)、Q8 (Tg 改善) |
| 0.6-0.7 | 3 | Q1 (分散性)、Q6 (环氧基应用) |
| 0.5-0.6 | 3 | Q5 (跨文献对比)、Q9 (阴离子聚合) |
| 0.4-0.5 | 4 | Q3 (力学对比)、Q10 (试剂选择) |

高相关性查询的特点：
- 问题意图明确，答案边界清晰
- 系统输出的"直接回答"段落能够准确复述问题意图

低相关性查询的特点：
- 对比类问题（如 Q3）需要列举多个方案，导致回答内容发散
- 结构化表格占比高，RAGAS 难以从表格中提取核心语义

### 6.3.3 自定义指标的优异表现

针对推荐系统的特殊需求，本研究设计了两个自定义评测指标：

**引用准确性（Citation Accuracy）= 1.000**

该指标验证回答中的所有引用是否可追溯到知识库中的真实记录。满分表明：
- 所有样本引用（如"SSBR-002"）均指向真实存在的样本
- 所有文献引用（如"Gao W 等人"）均可关联到原始 DOI
- 系统严格遵循"零幻觉"设计原则，不编造任何引用

**推荐完整性（Recommendation Completeness）= 1.000**

该指标检验结构化推荐卡片是否包含所有必要字段。满分表明每个推荐方案都包含：
- 推荐官能团类型
- 推荐官能化试剂
- 推荐官能化程度范围
- 预期改善效果

### 6.4.2 延迟构成分析

系统响应延迟由以下环节构成：

$$T_{total} = T_{retrieval} + T_{rerank} + T_{generation} + T_{postprocess}$$

**表 6-7：延迟构成分解**

| 环节 | 平均耗时 | 占比 | 说明 |
|------|----------|------|------|
| 向量检索 | ~200 ms | 3.3% | ChromaDB HNSW 搜索 |
| 交叉编码器重排 | ~800 ms | 13.2% | bge-reranker-base |
| LLM 生成 | ~4500 ms | 74.3% | GPT-4 API 调用 |
| 后处理 | ~560 ms | 9.2% | 结果格式化、引用验证 |
| **总计** | **~6060 ms** | **100%** | |

LLM 生成环节占据了约 75% 的响应时间，这是当前 RAG 系统的普遍瓶颈。未来可通过以下方式优化：
- 采用更快的推理模型（如 GPT-4-turbo）
- 实施流式输出（Streaming Response）
- 对常见问题进行回答缓存

3. **输出结构优化**：增加"直接回答"段落，强化引用验证逻辑

## 6.7 案例研究

本节通过三个具体案例，展示系统在实际应用场景中的表现。

### 6.7.1 案例 1：白炭黑分散性改善方案

**用户查询**：如何通过官能化改善白炭黑分散性？

**系统响应**（摘要）：

```markdown
## 直接回答

改善白炭黑分散性的核心策略是在 SSBR 分子链上引入极性官能团，
增强橡胶-填料界面相互作用。推荐以下三种官能化方案：

### 推荐方案 1：硅烷基官能化
- **官能团**：硅烷基 (-Si-OR)
- **推荐试剂**：γ-巯丙基三甲氧基硅烷 (MPTMS)
- **官能化程度**：3-5 wt%
- **预期效果**：Payne 效应降低 40-60%，拉伸强度提升 15-25%
- **数据来源**：SSBR-045, SSBR-046, SSBR-047 [DOI: 10.1016/j.polymer.2021.xxx]

### 推荐方案 2：羟基官能化
- **官能团**：羟基 (-OH)
- **推荐试剂**：环氧乙烷 (EO)
- **官能化程度**：5-10 wt%
- **预期效果**：填料分散性显著改善，tan δ(60°C) 降低 20-30%
- **数据来源**：SSBR-011, SSBR-012 [DOI: 10.1021/acs.macromol.2020.xxx]
```

**知识溯源路径**：

```
用户查询
```
