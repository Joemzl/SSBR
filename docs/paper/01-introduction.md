# 1. 引言 (Introduction)

## 1.1 研究背景

### 1.1.1 溶聚丁苯橡胶及其官能化技术概述

溶聚丁苯橡胶（Solution Styrene-Butadiene Rubber, SSBR）是一类通过阴离子聚合在有机溶剂中合成的弹性体材料。与传统乳聚丁苯橡胶（E-SBR）相比，SSBR 的分子量分布更窄、微观结构可控、杂质含量更低，因此被广泛用于绿色轮胎胎面等高性能橡胶制品。

SSBR 面临的一个实际问题是：分子链的非极性特征使其与白炭黑等极性填料的相容性较差。白炭黑（沉淀法二氧化硅）补强效果好、能降低滚动阻力，正在替代传统炭黑成为绿色轮胎配方的主流选择。但白炭黑表面富含硅羟基，极性强，与非极性 SSBR 基体在热力学上不相容。结果是填料容易团聚、分散不均，最终拖累硫化胶的力学和动态性能。

官能化改性是解决这个问题的常用方法。在 SSBR 分子链上引入极性官能团——羟基、羧基、氨基、环氧基、硅烷基等——可以改善橡胶与填料界面的相互作用。根据反应位点的不同，官能化方式分为三类：

- 端基官能化：在聚合物链端引入官能团，适用于活性阴离子聚合体系
- 链中官能化：通过共聚或接枝反应在主链上引入官能单体
- 接枝官能化：在已合成的 SSBR 上通过后反应接枝官能化试剂

官能化 SSBR 主要用于绿色轮胎（平衡低滚动阻力与湿地抓地力）、高性能轮胎（追求力学强度和耐磨性），以及其他对填料分散要求较高的橡胶制品。

### 1.1.2 SSBR 官能化研究现状与知识碎片化问题

过去二十年，SSBR 官能化领域积累了大量研究成果。研究者们探索了不同官能团类型、官能化程度、反应工艺对材料性能的影响。这些成果发表在 *Polymer*、*Macromolecules*、*Rubber Chemistry and Technology* 等期刊上，数量可观，但分散且缺乏整合。

这给实际使用带来了麻烦。

首先是数据分散。相关研究散布在数百篇独立文献中，没有统一的平台把它们串起来。研究者在做配方设计时，需要手动检索、筛选、对比大量文献，费时费力。

其次是实验条件的异质性。不同团队的测试标准不同——拉伸速度、温度、填料用量、硫化体系各有差异，跨文献的数据直接对比往往不可靠，有时甚至会误导判断。

第三是隐性知识难以提取。许多有价值的经验（比如"官能化程度过高会影响加工性能"）藏在论文的讨论部分，以定性描述的形式存在，传统数据库方法抓不到。

最后是更新滞后。专业数据库的构建和维护成本高，很难及时收录最新发表的研究。

这些问题直接影响配方设计的效率。研究者常常要花几周做文献调研，但仍可能漏掉关键信息，或者在不完整的数据基础上做出决策。

### 1.1.3 材料设计中的知识管理挑战

SSBR 官能化领域遇到的问题并非个例。材料科学数据有几个特点，使得传统知识管理方法很难奏效：

**高维异构性**。材料性能受组成、结构、工艺、测试条件等多重因素影响，很难用单一数据库架构覆盖所有变量。

**小样本特性**。实验材料科学的数据获取成本高，单项研究的样本量通常只有几个到几十个，撑不起传统机器学习方法所需的数据规模。

**知识表达多样性**。同一篇文献中，关键信息可能以数值表格、曲线图、文字描述等多种形式出现。

这些特点决定了材料科学需要一种不同的知识管理方法：能处理非结构化文本，能整合多源异构数据，能在小样本条件下提供可靠的推理支持。

## 1.2 人工智能在材料科学中的应用

### 1.2.1 传统数据库检索的局限性

传统材料数据库（如 ICSD、Materials Project、Polymer Database）在推动材料科学发展中发挥过重要作用。但在处理 SSBR 官能化这类"文献驱动"的研究领域时，它们有明显的局限。

覆盖范围有限。专业数据库主要收录标准化的晶体结构或基础物性数据，配方细节、工艺参数、应用性能这些实践导向的信息很少被覆盖。

查询方式刚性。传统关键词检索依赖精确匹配，不理解查询意图。用户搜索"改善白炭黑分散"，系统不会自动联想到"官能化改性"或"硅烷偶联剂"。

缺乏推理能力。数据库只能返回已有记录，无法基于现有知识做综合分析或趋势判断。

更新维护困难。结构化数据库的扩展需要专业人员做数据标注和质量控制，成本高、周期长。

### 1.2.2 大语言模型与检索增强生成技术

大语言模型（Large Language Models, LLMs）的快速发展为材料科学知识管理打开了新思路。LLMs 通过海量文本预训练，具备了较强的语言理解和生成能力，能处理复杂的自然语言查询并生成连贯的技术回答。

但直接把通用 LLM 用于专业领域有个麻烦：幻觉问题（Hallucination）。模型可能生成看起来合理、实际没有依据的内容。在材料科学中，这个问题尤其棘手——一个错误的官能化程度推荐可能导致实验失败，一个杜撰的性能数据可能误导后续研究。

检索增强生成（Retrieval-Augmented Generation, RAG）技术提供了一种解决思路。RAG 把信息检索和文本生成结合起来：

1. 检索阶段：根据用户查询，从专业知识库中找出最相关的文档片段
2. 生成阶段：把检索结果作为上下文，引导 LLM 基于真实证据生成回答

这种架构有几个好处：生成内容有文献来源支撑，可追溯；新增文献只需加入知识库，不用重新训练模型；通过构建专业知识库，可以快速适配特定研究领域。

## 1.3 研究目的与意义

基于上述背景，本研究构建了一个面向 SSBR 官能化配方设计的智能知识综合与推荐系统。系统要解决的问题是：

1. 从"单样本检索"升级为"多文献综合推理"——整合多篇文献的数据和结论，生成单一文献无法提供的综合性见解

2. 提供有边界约束的预测能力——基于数据趋势做合理外推，同时用 50% 数据范围约束防止过度外推

3. 确保引用可追溯——所有推荐内容必须能追溯到原始文献，不允许"幻觉"

4. 支持配方设计决策——根据用户的目标性能需求，生成包含官能团选择、官能化程度、填料体系等参数的配方建议

本研究的主要工作包括：

**多文献知识综合框架**。系统能整合多篇文献的数据，识别趋势和规律，而不只是返回单个最相关的样本。

**上下文外推边界控制策略（CEBC）**。通过指数衰减置信度模型和 50% 边界规则，在提供预测价值的同时控制外推风险。这是为了解决一个现实问题：用户查询的条件往往不在现有数据的覆盖范围内，但完全拒绝回答又不实用。

**多源冲突解决机制**。不同文献对同一问题的数据可能不一致。系统基于文献质量、实验条件相似度和发表时间，用加权融合的方式处理这些差异。

**领域知识库构建方法**。采用 YAML front matter + Markdown 正文的混合结构，把元数据和自然语言解读分开存储，同时支持统一检索。

**零幻觉引用机制**。在 RAGAS 评测中，系统的引用准确性达到 1.000，即所有生成内容都能追溯到原始文献。

**交叉编码器重排序**。集成 BGE-Reranker 模型后，上下文精度提升至 0.787。
