# 第五章 数据集与实验设置

## 5.1 SSBR 官能化知识库构建

本研究构建了一个专门针对溶聚丁苯橡胶（SSBR）官能化研究的领域知识库，作为 RAG 系统的检索基础。知识库的构建遵循结构化、可追溯、可扩展的设计原则。

### 5.1.1 数据来源与筛选标准

知识库的数据来源于国内外高水平学术期刊和学位论文，筛选标准如下：

**文献纳入标准**：
1. **主题相关性**：研究内容涉及 SSBR 官能化改性，包括链端官能化、侧链官能化、偶联反应等
2. **数据完整性**：文献中包含可量化的性能数据（力学、热学、动态性能中至少一类）
3. **方法可复现性**：明确报道了官能化试剂、反应条件、官能化程度等关键参数
4. **时效性**：优先收录近 10 年（2016-2026）的研究成果，经典文献不受此限制

**文献排除标准**：
- 仅含空白对照样本、未进行官能化改性的研究
- 数据表述模糊、无法提取定量信息的文献
- 重复发表或数据高度相似的文献（保留数据更完整者）

### 5.1.3 样本编号规则

知识库采用稀疏非连续的编号系统：

$$\text{Sample ID} = \text{SSBR-}\langle\text{序号}\rangle$$

其中序号为三位数字（如 SSBR-002、SSBR-115），数字不连续是因为：
1. 空白对照样本已从检索库中排除
2. 部分初始收录的样本因数据质量问题被移除
3. 编号一旦分配即固定，不因删除而重新编排

**重要约定**：由于编号的稀疏性，系统文档中禁止使用范围描述（如"SSBR-001~068"），应使用实际样本列表或数量统计。

知识库采用"元数据 + 解读文档"双层存储架构：

## 5.3 样本质量评估体系

### 5.3.1 质量评分维度

为实现基于数据完整性的样本降权，系统设计了多维度质量评分体系：

**表 5-3：质量评分维度与权重**

| 维度 | 权重 | 关键字段 | 子权重 |
|------|------|----------|--------|
| 官能化信息 | 30% | 官能化试剂 | 33% |
|            |     | 官能化程度 | 33% |
|            |     | 核心官能团 | 34% |
| 力学性能 | 25% | 拉伸强度 | 35% |
|          |     | 断裂伸长率 | 35% |
|          |     | 定伸应力 | 30% |
| 热学性能 | 15% | Tg | 100% |
| 动态性能 | 15% | tan δ | 100% |
| 文献来源 | 15% | DOI | 60% |
|          |     | 引文 | 40% |

**综合质量分数计算**：

$$Q_{overall} = \sum_{d \in \mathcal{D}} w_d \cdot Q_d$$

其中：
- $\mathcal{D} = \{\text{func}, \text{mech}, \text{therm}, \text{dyn}, \text{src}\}$
- $w_d$ 为维度权重
- $Q_d \in [0, 1]$ 为维度得分

### 5.3.2 质量分布统计

基于 68 个样本的质量评估结果：

**表 5-4：质量分布统计**

| 质量等级 | 分数范围 | 样本数 | 占比 | 处理策略 |
|----------|----------|--------|------|----------|
| 高质量 | ≥ 70% | 45 | 66.2% | 正常权重 |
| 中等质量 | 50-70% | 18 | 26.5% | 降权 20% |
| 低质量 | < 50% | 5 | 7.4% | 降权 50% + 标注 |

**统计指标**：
- 平均质量分数：72.3%
- 质量分数标准差：15.8%
- 最高分：96.2%（SSBR-002）
- 最低分：38.5%（SSBR-097）

### 5.3.3 低质量样本处理策略

低质量样本不被排除，而是采用以下处理策略：

1. **权重降低**：在检索排序时降低相似度得分

   $$\text{score}_{adj} = \text{score}_{raw} \times Q_{overall}$$

2. **标注提示**：在回答中标注"仅供参考"

   ```markdown
   **SSBR-097** (数据完整性: 38.5%, 仅供参考)
   - 拉伸强度: 15.2 MPa
   - 其他数据: 缺失
   ```

3. **引用说明**：在引用时说明数据局限性

### 5.4.4 Ground Truth 构建

为支持 RAGAS 评估，部分测试查询配备了标准答案（Ground Truth）：

**Ground Truth 构建原则**：
1. **数据来源明确**：答案中的所有数值均来自知识库中的原始文献
2. **引用可追溯**：每条关键信息标注来源样本
3. **结构化格式**：包含 ground_truth（答案）和 ground_truth_context（支持上下文）

**示例（Q1）**：

```python
EvalSample(
    question="如何通过官能化改善白炭黑分散性？",
    ground_truth="通过引入极性官能团（如羟基、羧基）或硅烷偶联剂，"
                 "可以增强 SSBR 与白炭黑表面的相互作用。"
                 "推荐官能化程度在 2.5-5 wt% 范围内。",
    ground_truth_context=[
        "SSBR-002 羧基官能化，8.7 wt%，拉伸强度 26.0 MPa，结合橡胶含量 67.82%",

    expected_samples=["SSBR-002", "SSBR-003", "SSBR-004", "SSBR-005"],
```

## 5.5 RAGAS 评测框架

### 5.5.1 RAGAS 简介

RAGAS（Retrieval-Augmented Generation Assessment）是由 Explodinggradients 团队开发的开源 RAG 系统评估框架，其核心特点：

1. **无需人工标注**：利用 LLM 自动评估生成内容质量
2. **多维度评估**：从忠实度、相关性、精度等多个维度综合评价
3. **可复现性强**：标准化的评估流程确保结果可复现

### 5.5.2 评估指标体系

**表 5-7：RAGAS 核心指标**

| 指标 | 定义 | 计算方法 |
|------|------|----------|
| **Faithfulness** | 回答对上下文的忠实度 | $\frac{\|\text{Supported Claims}\|}{\|\text{Total Claims}\|}$ |
| **Answer Relevancy** | 回答与问题的相关性 | $\frac{1}{n}\sum_{i=1}^{n} \text{sim}(q, q_i)$ |
| **Context Precision** | 检索排序质量 | 加权 Precision@K |
| **Context Recall** | 检索覆盖度 | $\frac{\|\text{Retrievable Info}\|}{\|\text{Ground Truth Info}\|}$ |

**忠实度（Faithfulness）**：

衡量生成回答中的每个声明（claim）是否可以从检索到的上下文中找到支持证据：

$$\text{Faithfulness} = \frac{|\{c : c \in \text{Claims}, \exists e \in \text{Context}, e \vdash c\}|}{|\text{Claims}|}$$

**回答相关性（Answer Relevancy）**：

通过反向问题生成计算回答与原问题的语义相似度：

$$\text{Answer Relevancy} = \frac{1}{n}\sum_{i=1}^{n} \cos(\mathbf{e}_q, \mathbf{e}_{q_i})$$

其中 $q_i$ 为根据回答反向生成的问题。

### 5.5.3 自定义评估指标

针对本系统的特点，设计了两个自定义指标：

**引用准确性（Citation Accuracy）**：

$$\text{Citation Accuracy} = \frac{|\text{Valid Citations}|}{|\text{Total Citations}|}$$

检查回答中的引用（如 "SSBR-002"、"Zhang 等人 (2023)"）是否指向知识库中的真实记录。

**推荐完整性（Recommendation Completeness）**：

$$\text{Completeness} = \frac{|\text{Present Fields}|}{|\text{Required Fields}|}$$

检查推荐卡片是否包含所有必要字段（官能团、试剂、程度、效果）。

## 5.8 本章小结

本章详细介绍了 SSBR 官能化 RAG 系统的数据集构建和实验设置：

1. **知识库构建**：收录 68 个官能化样本，来自 23 篇高水平文献，覆盖 12 种官能团类型

2. **存储架构**：采用"Excel 元数据 + Markdown 解读文档"双层架构，兼顾结构化查询和语义检索

3. **向量数据库**：使用 ChromaDB + HNSW 索引，检索延迟从 25-30 秒降至 1-2 秒

4. **质量评估**：设计五维度质量评分体系，支持低质量样本的智能降权

5. **测试集设计**：构建 24 个测试查询，覆盖综合分析和单样本问答两种模式

6. **评测框架**：采用 RAGAS 框架 + 自定义指标（引用准确性、推荐完整性），实现全面的系统评估

7. **实验设计**：包含基准对比、消融实验、用户研究三类实验，从多角度验证系统有效性
