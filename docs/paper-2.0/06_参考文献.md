## 说明

以上文献仅为示例，实际论文中应根据正文引用情况补充完整。建议：

1. **核心样本来源文献**：知识库中 68 个样本对应的原始文献应全部列入参考文献
2. **方法论文献**：RAG、RAGAS 等核心方法的原始论文
3. **技术基础文献**：向量检索、交叉编码器等技术的代表性论文
4. **领域综述**：SSBR 官能化、绿色轮胎等领域的综述文章

*参考文献数量建议：30-50 篇*
