## NMR 谱图解读

### 1. 最高接枝程度验证

OS10.1 展示了该系列中**最显著的 NMR 变化**：

```
乙烯基信号变化：
  原始 SSBR:      ████████████████████ 100%
  OS10.1:         ██████████████████░░ ~90%
                                    ↑
                              10% 被消耗

新信号强度：
  2.6 ppm: ████████ 强
  3.6 ppm: ████████ 强
```

### 2. 接枝率计算

| 参数 | 值 |
|------|-----|
| 投料比 ME/乙烯基 | 0.15:1 |
| 理论最大接枝率 | 15% |
| 实际接枝率 | 10.1% |
| 转化效率 | ~67% |

计算公式：
$$R_g = \frac{I_{2.6}}{2 \times I_{4.9,0}} \times 100\% = 10.1\%$$

### 3. 转化效率下降分析

| 样本 | ME投料 | 接枝率 | 转化效率 |
|------|--------|--------|----------|
| OS2.9 | 3% | 2.9% | 97% |
| OS7.8 | 9% | 7.8% | 87% |
| **OS10.1** | **15%** | **10.1%** | **67%** |

**转化效率下降原因**：

1. **空间位阻增加**: 更多接枝链限制后续反应
2. **反应动力学**: 乙烯基浓度降低
3. **副反应**: 高 ME 浓度可能导致自偶联

### 4. 微观结构最终态

| 结构单元 | 原始 SSBR | OS10.1 | 变化 |
|----------|----------|--------|------|
| 苯乙烯 | ~15 mol% | ~15 mol% | 不变 |
| 乙烯基 | 44.6 wt% | ~40 wt% | -10.1% |
| 1,4-PB | ~35 mol% | ~35 mol% | 不变 |
| 羟乙基硫醚 | 0 | 10.1 mol% | **最高** |

## 结论

1. **最高接枝率**: 10.1 mol%，系列最高
2. **明显 NMR 变化**: 乙烯基信号降低 ~10%
3. **转化效率**: 67%，受空间位阻限制
4. **分子量稳定**: 主链完整性保持
