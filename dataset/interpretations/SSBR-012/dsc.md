## DSC 曲线解读

### 1. Tg 升高最显著

OS10.1 展示了系列中**最高的 Tg 升高**（+8.4℃）：

| 羟基含量倍数 | Tg 升高倍数 |
|-------------|------------|
| 24 → 83 mmol/100g (3.5x) | 1.1 → 8.4℃ (7.6x) |

**非线性关系**: Tg 升高速度随羟基含量加速

### 2. 氢键网络密度最高

```
高密度氢键网络示意：

    OH---OH---OH
    |    |    |
   CH₂  CH₂  CH₂
    |    |    |
   ~~~  ~~~  ~~~

每个羟基可能参与多重氢键
```

### 3. Tg-羟基含量关系分析

| [OH] (mmol/100g) | Tg (℃) | ΔTg/Δ[OH] |
|------------------|--------|-----------|
| 0 → 24 | -26.1 → -25.0 | 0.046 ℃/mmol |
| 24 → 64 | -25.0 → -21.3 | 0.093 ℃/mmol |
| **64 → 83** | **-21.3 → -17.7** | **0.19 ℃/mmol** |

**趋势**: 斜率递增，表明氢键作用的协同效应

### 4. 氢键协同效应

| 羟基浓度 | 氢键类型 |
|----------|---------|
| 低 (24 mmol) | 主要为孤立氢键 |
| 中 (64 mmol) | 氢键对和短链 |
| **高 (83 mmol)** | **氢键网络** |

## 结论

1. **Tg = -17.7℃**: 系列最高，比未改性升高 8.4℃
2. **氢键网络**: 高浓度羟基形成三维氢键网络
3. **协同效应**: Tg 升高速度随羟基浓度加速
4. **滚阻最低**: 高交联+氢键约束使高温 tan δ 最低
