# SSBR-026 综合档案

## 研究亮点

本样本采用 **β-月桂烯共聚** 策略，将生物基萜烯单体引入 SBR 主链，开发出环保型高性能溶聚橡胶 (S-SMBR)。

## 核心发现

### 1. 生物基单体设计
- β-月桂烯 (β-myrcene) 来源于植物，是可再生的生物基单体
- 含量 15 wt%，在不显著改变基体性能的前提下引入功能性
- 通过阴离子聚合实现与苯乙烯、丁二烯的无规共聚

### 2. 微观结构特征
- 三元无规共聚物：苯乙烯 (27%)、β-月桂烯 (15%)、丁二烯 (58%)
- 乙烯基含量 50%，提供良好的动态性能基础
- Tg = -61°C，保持优异的低温柔性

### 3. 力学性能提升
- 拉伸强度 24.7 MPa，较纯 SBR 提升 16%
- 300% 模量 15.2 MPa，较纯 SBR 提升 23%
- 强度与韧性同步提升

### 4. 动态性能保持
- tanδ@0°C = 0.38，略优于纯 SBR
- tanδ@60°C = 0.15，与纯 SBR 相当
- 未牺牲轮胎动态性能

## 改性机理

β-月桂烯的作用机制：
1. **柔性贡献**: 萜烯长支链增加链段柔性
2. **界面改善**: 调节橡胶基体极性，改善与炭黑相容性
3. **加工优化**: 长支链改善混炼流动性
4. **交联参与**: 侧链双键可作为额外交联位点

## 应用前景

S-SMBR-026 代表了轮胎橡胶的绿色化发展方向，在保持甚至提升性能的同时，引入可再生的生物基成分，符合可持续发展理念。
