# SSBR-048 综合档案

## 样本概述

SSBR-048 是一种创新的星形、氨基官能化 SSBR (N-SSBR) 与白炭黑/炭黑复合填料体系。该研究采用共沉淀法制备复合材料，研究了氨基官能化和星形结构对动态性能的影响。

## 改性策略

### 氨基官能化

官能化试剂: [3-(2-氨基乙基)氨基丙基]三甲氧基硅烷

```
H₂N-CH₂-CH₂-NH-CH₂-CH₂-CH₂-Si(OCH₃)₃
```

功能特点：
- 氨基与白炭黑表面形成氢键
- 甲氧基可水解缩合
- 提供橡胶-填料化学连接

| 结构 | 多臂星形 |
| 分子量 | 351,000 |
| 优势 | 特殊流变性，低混炼能耗 |

## 性能-结构关系

### 氨基官能化效果

1. **分散改善**: 氨基与 Si-OH 的氢键作用
2. **界面增强**: 提高橡胶-填料相互作用
3. **Payne 效应降低**: 减少填料-填料聚集

### 星形结构效果

1. **加工性**: 低剪切粘度
2. **流变性**: 独特的非牛顿流动
3. **机械性能**: 高分子量提供强度

## 应用前景

- **绿色轮胎胎面**: 平衡滚动阻力和抗湿滑
- **特种橡胶制品**: 需要复合填料体系的应用
- **配方设计参考**: 官能化 SSBR + 复合填料
