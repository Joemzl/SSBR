## 官能化策略

### 仿生设计理念

受自然材料（如蚕丝、骨骼）中"牺牲键"启发，在预交联 SSBR 中构建牺牲氢键。

### TAD 点击化学

**反应特点**:
- 超快反应 (Alder-ene 反应)
- 无需催化剂
- 室温进行
- 不影响共价交联网络

**实验方法**:
```
预交联 SSBR 薄膜 (0.25 mm)
↓ 浸泡于 CH₂Cl₂ (4 h 溶胀)
↓ 转移至 TAD/CH₂Cl₂ 溶液 (12 h 反应)
↓ 洗涤、干燥
SSBR-TAD-x
```

### 后交联改性优势

传统方法在硫化前引入官能团，会影响交联密度。TAD 后交联改性：
- 不改变共价网络
- 精确评估牺牲键效应
- 独立控制物理/化学交联

## 微观结构

### 双网络结构

| 网络类型 | 形成方式 | 功能 |
|----------|----------|------|
| 共价网络 | 硫化交联 | 永久形状，弹性恢复 |
| 物理网络 | 氢键簇 | 临时形状，能量耗散 |

### 层级结构

```
脲唑基团 → 二聚体 → 多重态 → 簇 + 被困链段 → 微相分离
```

## 性能特点

### 力学性能

| 性能 | 改性效果 | 机理 |
|------|----------|------|
| 模量 | 显著增加 | 物理交联增加 |
| 韧性 | 大幅改善 | 牺牲键能量耗散 |
| 迟滞能 | 增加 | 氢键解离 + 被困链段塑性变形 |

当 TAD 接枝量达 5.32% 时，材料表现出类刚性塑料行为，有明显屈服。

### 形状记忆性能

#### 双重形状记忆

| 参数 | 值 |
|------|-----|
| 固定温度 | 室温 |
| 恢复温度 | 90°C |
| 形状固定率 Rf | 99% |
| 形状恢复率 Rr | 94% |

#### 三重形状记忆

| 步骤 | 温度 | 参数 |
|------|------|------|
| S0 → S1 | 90°C → 50°C | Rf1 = 81% |
| S1 → S2 | 50°C → 25°C | Rf2 = 75% |
| S2 → S1' | 25°C → 50°C | Rr2 = 87% |
| S1' → S0' | 50°C → 90°C | Rr1 = 80% |

### 自适应恢复

SSBR-TAD 还对有机蒸气表现出自适应形状恢复：
- CH₂Cl₂ (增塑效应)
- THF (增塑效应)
- 甲醇 (氢键断裂)

## 核心优势

### 1. 不改变共价网络

后交联改性保持原有硫化网络，可精确研究牺牲键效应。

### 2. 同时增强和功能化

一步实现：
- 力学性能增强
- 形状记忆功能

### 3. 简单工艺

- 浸泡法
- 室温反应
- 无需催化剂

## 应用场景

### 适用场景

1. **智能材料**: 形状记忆弹性体
2. **自适应器件**: 温度/溶剂响应性
3. **高韧性橡胶**: 需要能量耗散的应用

### 局限性

1. **加工性**: 需预先交联
2. **溶剂使用**: 需要 CH₂Cl₂
3. **TAD 成本**: 特种化学品
