# SSBR-065 形态分析解读

## 样本概述

SSBR-065 的微观形态通过 AFM (原子力显微镜) 进行表征，证实了氢键簇导致的微相分离结构。

## AFM DMT 模量图

### 测试方法

采用 Derjaguin-Muller-Toporov (DMT) 模式测量样品截面的力学模量分布。

### SSBR-TAD-3.56 形态

| 特征 | 描述 |
|------|------|
| 暗区 (软相) | SSBR 基体 |
| 亮区 (硬畴) | 氢键簇 |
| 硬畴尺寸 | ≈10 nm |
| 软相模量 | ≈10 MPa |
| 硬畴模量 | ≈40 MPa |

### SSBR-TAD-5.32 形态

与 SSBR-TAD-3.56 对比：
- **更密集的硬畴分布**
- **更高的模量**
- **微相分离更明显**

## 微相分离机理

### "笼效应"

预交联 SSBR 的共价网络产生"笼效应"：

1. **空间限制**: 共价网络限制 TAD 分子扩散
2. **非均匀分布**: 脲唑基团倾向于局部聚集
3. **多重态形成**: 邻近脲唑基团形成氢键复合物

### 与文献对比

| 体系 | 脲唑分布 | 结构 |
|------|----------|------|
| TAD 改性聚丁二烯 (均匀) | 均匀 | 仅二聚体和少量多重态，无簇 |
| TAD 改性预交联 SSBR | 非均匀 | 二聚体 → 多重态 → 簇 |

### 额外因素

苯乙烯单元的空间位阻也贡献于非均匀分布：
- 相邻苯基阻碍 TAD 分子接近
- 促进脲唑基团局部富集

## 相分离结构

### 软相

- **组成**: 低脲唑含量的 SSBR 基体
- **Tg**: ≈-60°C
- **模量**: ≈10 MPa

### 硬畴

- **组成**: 氢键簇 + 被困聚合物链段
- **热转变**: 室温以上
- **模量**: ≈40 MPa
- **尺寸**: ≈10 nm

## 形态与性能关系

### 力学性能

| 形态特征 | 对应性能 |
|----------|----------|
| 硬畴 (物理交联) | 模量增加 |
| 氢键簇 (牺牲键) | 能量耗散、韧性增强 |
| 双网络结构 | 高强高韧 |

### 形状记忆性能

| 形态特征 | 对应功能 |
|----------|----------|
| 共价网络 | 永久形状固定 |
| 氢键簇 | 临时形状固定 |
| 簇的温度依赖性 | 多阶段形状恢复 |
