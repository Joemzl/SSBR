# SSBR-081 NMR 结构解读

## 样本概述

SSBR-081 研究了脂肪酸苄酯作为生物基增塑剂的应用，NMR 主要用于表征增塑剂结构和相容性。

## 增塑剂结构表征

### 脂肪酸苄酯结构
脂肪酸苄酯的一般结构：
```
Ph-CH₂-O-CO-R
```
其中 R 为脂肪酸链（C12-C18）

### NMR 特征峰
脂肪酸苄酯的典型 NMR 信号：
- δ 7.3-7.4 ppm：苯环芳香氢
- δ 5.1 ppm：亚甲基 -CH₂-
- δ 2.3 ppm：α-亚甲基
- δ 1.2-1.6 ppm：脂肪链亚甲基
- δ 0.9 ppm：末端甲基

## 橡胶-增塑剂相互作用

### 相容性机制
脂肪酸苄酯与 SSBR/BR 的相容性：
- 苄基与苯乙烯链段的 π-π 相互作用
- 脂肪链与丁二烯链段的范德华力
- 整体溶解度参数匹配

### 迁移稳定性
良好的相容性带来：
- 低迁移倾向
- 长期稳定性
- 抗析出能力

## 与传统芳烃油对比

### 结构差异
| 特性 | 脂肪酸苄酯 | 芳烃油 |
|------|-----------|--------|
| 芳香含量 | 单苯环 | 多环芳烃 |
| 极性 | 中等 | 低 |
| 来源 | 生物基 | 石油基 |
| PAHs 含量 | 极低 | 较高 |

### 环保优势
- 不含多环芳烃
- 符合环保法规
- 可持续来源

## 结论

脂肪酸苄酯的分子结构赋予其良好的橡胶相容性和增塑效果，是传统芳烃油的优良替代品。
