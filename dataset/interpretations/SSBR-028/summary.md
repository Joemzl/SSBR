# SSBR-028 综合档案

## 样本概述

SSBR-028 来自中国研究团队关于 SSBR 结构特征对橡胶复合材料性能影响的研究。本文献系统研究了分子结构参数与最终性能的关系。

## 研究亮点

### 1. 结构-性能关系研究

本研究的核心是建立 SSBR 分子结构与复合材料性能的定量关系：

| 结构参数 | 对性能的影响 |
|----------|--------------|
| 苯乙烯含量↑ | Tg↑, 湿地抓地力↑, 耐磨性↓ |
| 乙烯基含量↑ | 交联效率↑, 弹性↓ |
| Mn↑ | 强度↑, 加工性↓ |
| PDI↑ | 加工性↑, 性能均一性↓ |

### 2. 轮胎性能三角优化

研究为"魔三角"优化提供分子设计指导：
- 湿地抓地力：高苯乙烯含量有利
- 滚动阻力：需综合考虑 Tg 和填料分散
- 耐磨性：分子量和交联密度是关键

### 3. 分子设计策略

为 SSBR 分子设计提供指导原则：
- 根据目标应用选择最优结构参数
- 平衡加工性与最终性能
- 考虑与填料体系的匹配
