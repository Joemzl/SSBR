# SSBR-032 综合档案

## 研究亮点

本样本采用 **APTMS 接枝官能化** SSBR 结合 **石墨烯/白炭黑杂化填料**，探索了新型纳米碳材料在轮胎橡胶中的应用。

## 核心发现

### 1. 双重官能化策略
- **橡胶改性**: APTMS 通过巯基-烯点击反应接枝到 SSBR 乙烯基
- **填料杂化**: 石墨烯与白炭黑形成协同填料体系
- **界面桥接**: APTMS 的硅烷基团与填料共价键合

### 2. 形貌特征
- 石墨烯呈单层或少层分散
- 白炭黑均匀分布，团聚减少
- 杂化填料网络结构优化

### 3. 力学性能提升
- 拉伸强度 18.5 MPa，较纯白炭黑体系提升 14%
- 300% 模量 9.8 MPa，提升 15%
- 断裂伸长率 485%，保持良好韧性

### 4. 动态性能优化
- tanδ@0°C = 0.45，湿抓性能优异
- tanδ@60°C = 0.09，低滚阻特性
- 实现湿抓/滚阻的良好平衡

## 改性机理

APTMS 官能化 + 杂化填料的协同作用：

1. **化学键合**: APTMS 的 -Si(OCH₃)₃ 与 SiO₂ 表面形成 Si-O-Si 共价键
2. **氢键作用**: -NH₂ 基团与石墨烯表面含氧官能团形成氢键
3. **填料协同**: 石墨烯二维结构与白炭黑零维颗粒形成三维填料网络
4. **应力传递**: 紧密界面实现高效应力传递

## 技术创新点

1. **新型填料体系**: 首次将石墨烯/白炭黑杂化应用于轮胎 SSBR
2. **界面设计**: APTMS 实现橡胶-填料-填料的三元界面优化
3. **性能平衡**: 在力学增强的同时改善动态性能

## 应用前景

石墨烯/白炭黑杂化填料代表了轮胎填料技术的前沿方向，有望进一步提升绿色轮胎的综合性能。
