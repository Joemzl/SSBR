接枝率增加趋于饱和：
- 0.2→0.4 phr: +0.2%
- 0.4→0.8 phr: +0.7%
- 0.8→1.6 phr: +0.5%（用量翻倍，增量反而减少）

## ⚠️ 凝胶化问题

### 凝胶含量急剧增加

| 样本 | 凝胶含量 | 相对变化 |
|------|---------|---------|
| 0.8 phr | 基准 | - |
| **1.6 phr** | **+462%** | **急剧增加** |

### 凝胶化机理

```
过量 MPA 导致的自由基副反应：

正常接枝：
SSBR-CH=CH₂ + HS-R-COOH → SSBR-CH₂-CH₂-S-R-COOH

副反应（过量时）：
SSBR-CH=CH₂ + ·S-R → SSBR-CH·-CH₂-S-R
                ↓
              交联
                ↓
        SSBR-CH-CH₂-S-R
              |
              |  ← 链间交联
              |
        SSBR-CH-CH₂-S-R
```

### 凝胶化的危害

| 危害 | 描述 |
|------|------|
| 加工困难 | ML 显著升高 |
| 分散受阻 | 凝胶阻碍填料分散 |
| 性能下降 | 界面相互作用减弱 |

## FTIR 特征

| 波数 | 归属 | Sample 5 |
|------|------|----------|
| 1707 cm⁻¹ | C=O (羧基) | 最强 |
| 909/994 cm⁻¹ | 乙烯基 | 最低 |

### 乙烯基消耗最多

但接枝效率降低：
- 部分乙烯基参与凝胶化交联
- 而非有效接枝

## 结论

1. **最高接枝率 3.1%**: 但效率降低
2. **凝胶化严重**: +462%
3. **乙烯基消耗最多**: 但部分用于交联而非接枝
4. **验证过量危害**: 确认 1.6 phr 超过最优
