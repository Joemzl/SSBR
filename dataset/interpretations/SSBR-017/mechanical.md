## 性能下降原因分析

### 1. 凝胶化问题

```
凝胶含量变化（Figure 5）：

凝胶含量
    ↑
    │                    ★ Sample 5
    │                   ↗ (+462%)
    │         ●────●───●
    │        ↗
    │  ●────●
    └────────────────────→ MPA 用量
       0  0.2 0.4 0.8 1.6

1.6 phr 时凝胶含量急剧增加！
```

### 2. 凝胶化导致的问题

| 问题 | 影响 |
|------|------|
| 橡胶基体交联 | 分散受阻 |
| 填料包覆不足 | 团聚加剧 |
| 加工粘度增加 | ML 升高 |
| 有效交联降低 | MH-ML 降低 |

### 3. 硫化迟延回归

tc₉₀ 从 19.5 min 反弹至 27.4 min：
- 凝胶化导致分散变差
- 更多促进剂被填料吸附

## 关键教训

### 最优用量确认

| MPA 用量 | 综合性能 | 评价 |
|----------|---------|------|
| 0 phr | 基准 | 参考 |
| 0.2 phr | 改善 | 初步效果 |
| 0.4 phr | 明显改善 | 良好 |
| **0.8 phr** | **最优** | **推荐** |
| 1.6 phr | **下降** | **过量** |

### 过量的危害

1. **凝胶化**: 基体过度交联
2. **分散变差**: L 值升高 113%
3. **界面弱化**: 结合胶降低 18%
4. **性能恶化**: 动态性能全面下降

## 结论

1. **1.6 phr 过量**: 超过最优用量导致性能下降
2. **凝胶化关键**: 凝胶含量急剧增加是主因
3. **分散恶化**: L 值显著升高
4. **验证最优**: 确认 0.8 phr 为最佳用量
