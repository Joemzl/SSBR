## DSC 曲线解读

### 1. Tg 升高分析

OS7.8 的 Tg 升高 4.8℃，显著高于 OS2.9（+1.1℃）：

| 因素 | 影响 |
|------|------|
| 羟基密度 | 64 vs 24 mmol/100g，增加 167% |
| 氢键数量 | 大幅增加 |
| 链运动限制 | 显著增强 |

### 2. 氢键网络形成

```
高羟基密度形成的氢键网络：

  -OH···HO-
    \     /
     氢键
    /     \
  -OH···HO-

形成三维氢键网络，限制链段运动
```

### 3. Tg-羟基含量线性关系

| 数据点 | [OH] (mmol/100g) | Tg (℃) |
|--------|------------------|--------|
| SSBR | 0 | -26.1 |
| OS2.9 | 24 | -25.0 |
| **OS7.8** | **64** | **-21.3** |
| OS10.1 | 83 | -17.7 |

**线性拟合**: Tg ≈ -26.1 + 0.1 × [OH]

对于 OS7.8: Tg = -26.1 + 0.1 × 64 = -19.7℃ (理论) vs -21.3℃ (实测)

### 4. 低温性能评估

| 评估项目 | OS7.8 表现 |
|----------|-----------|
| Tg 绝对值 | -21.3℃（良好） |
| 与室温差距 | ~46℃（裕度较大） |
| 冬季使用 | 满足要求 |
| 极寒环境 | 需谨慎评估 |

## DMA 动态热分析

### tan δ-T 曲线特征

| 参数 | OS7.8 特点 |
|------|-----------|
| Tg (DMA) | 约 -21℃ |
| tan δ 峰值 | 随交联密度增加而降低 |
| 峰宽 | 正常 |
| 高温 tan δ | 较低（有利于低滚阻） |

### 交联剂用量对 tan δ 的影响

| A³ 用量 | tan δmax 趋势 |
|---------|--------------|
| 1.5 phr | 较高 |
| 3.0 phr | 中等 |
| 5.0 phr | 较低 |

**机理**: 交联密度增加 → 链运动受限 → tan δ 降低

## 与轮胎性能关联

### 温度-性能对应

| 温度区间 | 对应性能 | OS7.8 预期 |
|----------|----------|-----------|
| Tg附近 (-21℃) | 最大阻尼 | 在此温度 |
| 0℃ | 抗湿滑 | 中等 tan δ |
| 60℃ | 滚动阻力 | 较低 tan δ |

### 性能预测

| 性能 | 评估 | 说明 |
|------|------|------|
| 抗湿滑 | ★★★☆ | Tg 偏低于最优范围 |
| 滚动阻力 | ★★★☆ | 高温 tan δ 较低 |
| 低温性能 | ★★★★ | Tg = -21.3℃ 良好 |

## 热力学分析

### 热容变化

| 参数 | 预期值 |
|------|--------|
| ΔCp (Tg 处) | 与羟基含量相关 |
| 协同运动单元 | 可能减小 |

### 松弛行为

羟基间氢键影响松弛动力学：
- **α 松弛**: 主链段运动，Tg 处
- **β 松弛**: 侧基运动，可能受羟基影响

## 结论

1. **Tg = -21.3℃**: 比未改性 SSBR 升高 4.8℃
2. **氢键网络**: 64 mmol/100g 羟基形成显著氢键网络
3. **良好低温性能**: Tg 仍远低于室温
4. **DMA 表现**: tan δ 随交联密度增加而降低
