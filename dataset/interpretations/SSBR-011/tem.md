## 网络拓扑结构

### oxa-Michael 交联网络

```
三官能交联 (A³):

      ~~~OH
         \
    O-C(=O)-CH=CH₂
         |
  ~~~O-CH₂-CH₂-C(=O)-O~~~
         |
    O-C(=O)-CH₂-CH₂-O~~~
         /
      ~~~OH

每个 A³ 分子可连接 3 条橡胶链
```

## 应变硬化行为

### Mooney-Rivlin 分析

| 应变区间 | 行为特征 |
|----------|----------|
| 低应变 | 线性响应 |
| 中应变 | 软化区 |
| 高应变 | 应变硬化 |

### 与官能度关系

高官能度交联剂（A⁴）赋予：
- 更高的应变硬化程度
- 更早的硬化起始
- 更高的拉伸强度和模量

## 结论

1. **纯胶体系**: Zhang_2018 未进行 TEM 表征
2. **最优羟基含量**: 64 mmol/100g 实现高效交联
3. **均匀网络**: oxa-Michael 反应形成规整网络
4. **性能可调**: 通过交联剂用量和官能度调节性能
