## NMR 谱图解读

### 1. 接枝反应完整性验证

OS7.8 的 NMR 特征：

```
乙烯基消耗:
  4.9 ppm (CH₂=) → 降低 ~8%
  5.3 ppm (=CH-) → 降低 ~8%

新官能团信号:
  2.6 ppm (-CH₂-S-CH₂-) → 明显新峰
  3.6 ppm (-CH₂-OH) → 明显新峰
```

### 2. 接枝率计算

| 参数 | 值 |
|------|-----|
| 投料比 ME/乙烯基 | 0.09:1 |
| 理论最大接枝率 | 9% |
| 实际接枝率 | 7.8% |
| 转化效率 | ~87% |

计算公式：
$$R_g = \frac{I_{2.6,x}}{2 \times I_{4.9,0}} \times 100\% = 7.8\%$$

### 3. 微观结构变化

| 结构单元 | 未改性 SSBR | OS7.8 | 变化量 |
|----------|------------|-------|--------|
| 苯乙烯 | 基准 | 不变 | - |

| 1,4-PB | 基准 | 不变 | - |

## 官能化效率分析

### 反应条件优化

| 参数 | OS2.9 | OS7.8 | OS10.1 |
|------|-------|-------|--------|
| ME/乙烯基 | 0.03 | 0.09 | 0.15 |
| 实际接枝率 | 2.9% | 7.8% | 10.1% |
| 转化效率 | 97% | 87% | 67% |

**观察**: ME 用量增加时，转化效率略有下降

### 可能原因

1. **空间位阻**: 更多接枝链导致位阻增加
2. **自由基竞争**: 高浓度可能导致副反应
3. **传质限制**: 溶液粘度增加

## 结论

1. **接枝率 7.8%**: 通过 NMR 定量确认
2. **中等转化效率**: ~87%，高于预期
3. **结构完整**: 分子量无显著变化
4. **成功官能化**: 羟基和硫醚键有效引入
