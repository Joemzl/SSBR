# SSBR-031 TEM/分散性解读

## 样本基本信息

- **样本编号**: SSBR-031
- **官能化试剂**: 3-巯基丙酸 (3-MPA)
- **官能化程度**: 9.6 wt%
- **分析方法**: MD 模拟 - 径向分布函数 g(r)

## 一、白炭黑分散性评价

### MD 模拟分散性指标

文献通过计算 Si-Si 径向分布函数 g(r) 来评估白炭黑分散性。峰位置 r 值越大，表示白炭黑颗粒间距越大，分散越好。

| 模拟样本 | 接枝量 (wt%) | g(r) 峰位置 r (Å) | 分散性评价 |
|---------|-------------|------------------|-----------|
| g0 | 0 | 13.7 | 差 |
| g1 | 2.4 | 14.1 | 一般 |
| g2 | 4.3 | 14.8 | 良 |
| **g3** | **9.5** | **15.5** | **良** |
| g4 | 14.2 | 15.7 | 优 |
| g5 | 20.8 | 15.0 | 良 |
| g6 | 26.9 | 14.3 | 一般 |

### 分散性变化趋势

```
接枝量:  0% → 9.5% → 14.2% → 26.9%
r (Å): 13.7 → 15.5 → 15.7  → 14.3
       差    良     优      一般
```

## 二、热力学参数（实验验证）

### 填料-橡胶粘附与絮凝参数

| 样本 | Wrf (mJ/m²) | ΔW (mJ/m²) | ka (10⁻³ S⁻¹) |
|------|------------|-----------|--------------|
| M0 | 51.2 | 13.0 | 3.98 |
| M1 | 53.3 | 11.8 | 3.56 |
| M2 | 55.8 | 8.1 | 3.12 |
| **M3** | **62.1** | **4.6** | **2.82** |

- **Wrf**: 填料-橡胶粘附能（越大越好）
- **ΔW**: 填料絮凝驱动力（越小越好）
- **ka**: 填料絮凝速率常数（越小越好）

### 核心发现

1. **粘附能 Wrf 增加**: 从 51.2 增至 62.1 mJ/m²，提升 21.3%
2. **絮凝驱动力 ΔW 降低**: 从 13.0 降至 4.6 mJ/m²，降低 64.6%
3. **絮凝速率 ka 降低**: 从 3.98 降至 2.82 × 10⁻³ S⁻¹，降低 29.1%

## 三、分散性改善机理

### 氢键网络形成

3-MPA 的羧基与白炭黑表面硅羟基形成氢键：

```
    SSBR-COOH ···· HO-Si-O-Si
              ↑
           氢键
```

### 界面相互作用增强

- 结合能从 -337.8 kcal/mol (g0) 增至 257.5 kcal/mol (g3)
- 正值结合能表示良好的相容性
