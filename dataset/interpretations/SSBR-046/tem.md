## 形貌解读

### 概述

本文献使用 TEM 研究了 SSBR/SiO₂/CB 复合材料中填料的分散状态和网络结构。TEM 观察揭示了不同 SiO₂/CB 配比对填料分散和性能的影响机理。

### TEM 测试条件

- **设备**: Hitachi H800-1 透射电子显微镜
- **加速电压**: 200 kV
- **样品制备**: 超薄切片机在 -100°C 下切片，铜网收集

### 图像对比度

TEM 图像中：
- **浅色区域**: 橡胶基体（SSBR）
- **透明深色**: 炭黑（CB）粒子
- **不透明深色**: 白炭黑（SiO₂）粒子

### 形态学观察

#### Fig. 2(a1): SSBR/CB (0/70) - 纯炭黑体系

| 特征 | 描述 |
|------|------|
| CB 粒径 | ~30 nm 球形粒子 |
| 聚集状态 | 形成明显的填料网络 |
| 分散评价 | 存在聚集，Payne 效应大 |
| 导电性 | 优异，适合抗静电 |

**分析**: CB 粒子的六元环平面上电子可以流动，因此形成导电网络。但填料聚集导致高 Payne 效应和高内摩擦。

#### Fig. 2(a2): SSBR/SiO₂/CB (20/50) - 最佳配比

| 特征 | 描述 |
|------|------|
| 结构特点 | 不规则 SiO₂ 嵌入 CB 网络 |
| 分散评价 | **最佳**，优于纯 CB 或纯 SiO₂ 体系 |
| 网络结构 | CB 网络部分被 SiO₂ 打断 |
| 性能影响 | 力学性能最高，Payne 效应最低 |

**分析**: 适量 SiO₂ 的加入削弱了 CB 的填料网络，提高了纳米级分散。Si-75 偶联剂增强了 SiO₂ 与橡胶的界面结合。

#### Fig. 2(a3): SSBR/SiO₂/CB (35/35) - 渗滤阈值

| 特征 | 描述 |
|------|------|
| 结构特点 | SiO₂ 和 CB 形成交织网络 |
| 分散评价 | 良好 |
| CB 间距 | CB 粒子被 SiO₂ 分隔一定距离 |
| 导电性 | 抗静电性能的渗滤阈值 |

**分析**: 当 SiO₂/CB = 35/35 时，CB 之间的隔离距离达到临界值，是抗静电性能的渗滤阈值。

#### Fig. 2(a4): SSBR/SiO₂ (70/0) - 纯白炭黑体系

| 特征 | 描述 |
|------|------|
| SiO₂ 粒径 | 20-40 nm 不规则粒子 |
| 聚集状态 | 形成填料网络 |
| 分散评价 | 存在聚集 |
| 导电性 | 绝缘，易积累静电 |

**分析**: SiO₂ 表面由 Si-O 四面体构成，电子难以流动，呈现绝缘性。纯 SiO₂ 体系会导致静电积累问题。

### 填料分散机理

#### 双相填料协同效应

1. **物理机理**: 
   - SiO₂ 的不规则形状打断 CB 的链状聚集
   - 两种填料的尺寸差异促进相互穿插

2. **化学机理**:
   - Si-75 偶联剂提高 SiO₂ 与 SSBR 的相容性
   - 预混工艺（先混 SiO₂/Si-75）提高后续 CB 分散

3. **加工机理**:
   - 预混 SiO₂ 提高了混炼胶粘度
   - 高粘度下 CB 受到更强剪切作用，分散更好

### 形态-性能关联

| 配方 | 填料分散 | Payne 效应 | 力学性能 | 导电性 |
|------|---------|-----------|---------|--------|
| 0/70 | 中等 | 最大 | 中等 | 优异 |
| 20/50 | **最佳** | **最小** | **最佳** | 良好 |
| 35/35 | 良好 | 较小 | 良好 | 渗滤阈值 |
| 70/0 | 中等 | 较大 | 良好 | 绝缘 |

### 抗静电渗滤阈值

根据隧道导电理论：
- CB 间隔离距离 < 10 nm: 电子可隧穿，具有抗静电性
- CB 间隔离距离 > 10 nm: 绝缘性

文献确定 SiO₂/CB = 35/35 为 70 phr 总填料量时的抗静电渗滤阈值。
