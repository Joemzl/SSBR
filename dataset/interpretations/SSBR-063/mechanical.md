# SSBR-063 力学性能解读

## 样本背景

SSBR-063 是白炭黑填充的 SSBR/顺丁橡胶 (BR) 并用胶，研究拉伸过程中的体积变化和形貌演变。

## 拉伸性能分析

### 数据来源
- **来源层级**: L2 (文献 Fig.5 应力-应变曲线)
- **测试方法**: 单轴拉伸

### 应力-应变曲线特征

| 参数 | 数值 | 单位 |
|------|------|------|
| 拉伸强度 | ~18.5 | MPa |
| 断裂伸长率 | ~520 | % |
| 100% 定伸应力 | ~2.0 | MPa |
| 300% 定伸应力 | ~8.5 | MPa |

### 曲线特点

1. **初始模量区**: 低应变区呈线性响应
2. **应变软化**: 中等应变时出现轻微软化
3. **应变硬化**: 高应变时表现明显硬化行为

## 体积变化研究

### 测试方法

文献采用体积膨胀测量技术，研究拉伸过程中的体积变化：

1. **低应变阶段** (0-100%): 体积基本不变，橡胶链段取向
2. **中应变阶段** (100-300%): 开始出现微空穴
3. **高应变阶段** (>300%): 空穴增长和合并

### 体积变化机制

```
拉伸 → 填料-橡胶脱粘 → 微空穴形成 → 体积膨胀
```

影响因素：
- 填料分散状态
- 界面结合强度
- 橡胶相容性

## 并用胶性能特点

### SSBR/BR 配比优化

| 相 | 特性 | 贡献 |
|----|------|------|
| SSBR | 抗湿滑、强度 | 力学性能 |
| BR | 耐磨、弹性 | 耐磨性和回弹性 |

### 协同效应

并用胶体系结合了两种橡胶的优点：
- SSBR 提供良好的抗湿滑性
- BR 提供优异的耐磨性和低滚动阻力

## 综合评价

SSBR-063 的研究重点在于理解拉伸形变过程中的微观结构演变，为优化白炭黑/橡胶复合材料提供理论指导。
