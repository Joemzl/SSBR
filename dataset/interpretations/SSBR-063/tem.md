# SSBR-063 TEM/SEM 形貌解读

## 样本背景

SSBR-063 研究白炭黑填充 SSBR/BR 并用胶在拉伸过程中的形貌演变。

## 形貌表征

### 数据来源
- **来源层级**: L1 (文献 Fig.3)
- **表征方法**: SEM (扫描电子显微镜)

### 初始形貌

拉伸前的形貌特征：

1. **白炭黑分散**: 填料在基体中分布相对均匀
2. **两相结构**: SSBR 和 BR 相可区分
3. **界面区域**: 填料优先分布在某一相中

## 拉伸过程形貌演变

### 原位拉伸 SEM 观察

| 应变 | 形貌变化 |
|------|----------|
| 0% | 初始状态，无明显空穴 |
| 100% | 开始出现微空穴 |
| 200% | 空穴增长，数量增加 |
| 300% | 空穴合并，形成裂纹前驱体 |
| >400% | 空穴连通，材料断裂 |

### 空穴形成机制

```
拉伸应力 → 填料-橡胶界面应力集中 → 界面脱粘 → 微空穴形成
                                    ↓
              空穴增长 → 空穴合并 → 宏观断裂
```

## 体积变化与形貌关联

### 体积膨胀测量

文献将体积变化与形貌演变相关联：

1. **低应变** (<100%): 体积几乎不变
   - 橡胶链段取向为主
   - 无明显空穴

2. **中应变** (100-300%): 体积开始增加
   - 填料-橡胶脱粘
   - 微空穴形成

3. **高应变** (>300%): 体积显著增加
   - 空穴快速增长
   - 接近断裂

## 并用胶相形貌

### 两相分布

SSBR/BR 并用胶通常表现为海岛结构：
- **连续相**: 主要组分
- **分散相**: 次要组分
- **填料分布**: 优先分布在极性更高的相中

## 技术意义

理解拉伸过程中的形貌演变有助于：
1. 优化填料分散
2. 改善界面结合
3. 提高材料耐久性
