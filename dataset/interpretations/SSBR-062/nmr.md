# SSBR-062 NMR/FT-IR 结构表征解读

## 样本概述

SSBR-062 使用甲酸/H₂O₂体系通过原位生成过氧甲酸对 SSBR 进行环氧化。本文档解读环氧化反应的结构表征结果。

## ¹H NMR 分析

### 特征峰归属

文献 Figure 3b 展示了 SSBR 和 ESSBR 的 ¹H NMR 谱图：

| 化学位移 (ppm) | 归属 | SSBR | ESSBR |
|----------------|------|------|-------|
| 4.90 (f,l) | 1,2-乙烯基 =CH₂ | ✓ | ✓ (基本不变) |
| 5.25 (d,e) | 1,4-加成 =CH | ✓ | ↓ (降低) |
| 2.55 (j,k) | 反式环氧 -CH | - | ✓ (新峰) |
| 2.80 (h,i) | 顺式环氧 -CH | - | ✓ (新峰) |
| 3.64 (m) | 羟基 -CH (开环副产物) | - | 微量 |

### 环氧化度计算公式

```
X% = (A_epox - A_Hest) / (A_epox - A_Hest + A_1,4 + A_1,2) × 100
```

其中：
- A_epox: 2.55 和 2.80 ppm 环氧峰积分
- A_Hest: 2.55 ppm 苯乙烯亚甲基估计值
- A_1,4: 5.25 ppm 1,4-聚丁二烯峰积分
- A_1,2: 4.9 ppm 乙烯基峰积分

### 反应选择性

实验结果表明：
- **1,4-顺/反式双键**: 优先被环氧化
- **1,2-乙烯基**: 反应活性较低，基本保持不变

这说明 1,4-加成单元的双键反应活性高于 1,2-加成的悬挂乙烯基。

## FT-IR 分析

### 特征吸收峰

文献 Figure 3a 展示了 FT-IR 光谱：

| 波数 (cm⁻¹) | 归属 | 变化 |
|-------------|------|------|
| 760 | 1,4-顺式 C=C | 保留 |
| 966 | 1,4-反式 C=C | 降低 |
| 911 | 1,2-乙烯基 C=C | 基本不变 |
| 1260 | C-O-C 对称伸缩 | 新峰 (环氧) |
| 801 | C-O-C 不对称伸缩 | 新峰 (环氧) |
| 3100-3600 | -OH 宽峰 | 微弱 (开环副产物) |

### 环氧化确认

FT-IR 光谱中 1260 和 801 cm⁻¹ 出现的新吸收峰明确证实了环氧基团已成功引入 SSBR 分子链。

环氧化后分子量略有增加，PDI 变化不大，说明：
- 副反应少
- 反应可控
- 未发生明显的链断裂或交联
