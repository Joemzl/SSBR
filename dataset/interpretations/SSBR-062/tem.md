# SSBR-062 TEM 形态分析解读

## 样本概述

SSBR-062 为环氧化 SSBR，通过 TEM 观察其与白炭黑复合后的微观形态，评价环氧化对填料分散的影响。

## TEM 形态观察

### 分散性对比

文献 Figure 5 展示了不同样品的 TEM 图像：

| 样品 | 分散性描述 | 评级 |
|------|------------|------|
| PS-SSBR/BR (纯白炭黑) | 明显团聚，形成大块聚集体，相界面清晰 | 差 |
| E7-SSBR/BR | 团聚减少 | 一般 |
| E10-SSBR/BR | 分散性改善 | 良 |
| E15-SSBR/BR | 接近 TESPD 改性效果 | 良+ |
| E20-SSBR/BR | 与 TESPD 相当 | 优 |
| E25-SSBR/BR | 优于 TESPD | 最优 |
| TS-SSBR/BR (TESPD) | 参考标准 | 优 |

### 形态特征

1. **未改性体系 (PS-SSBR/BR)**:
   - 白炭黑颗粒明显团聚
   - 形成大量团块
   - 白炭黑与橡胶基体相界面清晰
   - 白炭黑表面硅羟基导致亲水性聚集

2. **ESSBR 改性体系**:
   - 白炭黑分散性随环氧化度增加而改善
   - 相界面变得模糊（界面相互作用增强）
   - 颗粒尺寸减小，分布更均匀

## 分散性改善机理

### 化学键合机制

```
ESSBR-环氧基 + 白炭黑-Si-OH → ESSBR-O-Si-白炭黑 + H₂O
```

环氧基与硅羟基的开环反应：
1. 降低白炭黑表面亲水性
2. 增加白炭黑与橡胶的相容性
3. 形成化学键合界面

### 抑制再团聚

化学键合的优势：
- 白炭黑与橡胶形成稳定的化学相互作用
- 分散状态不易因后续加工而破坏
- 比物理吸附更稳定

## 结合胶含量

### 测试结果

文献 Figure 6 展示了结合胶含量：

| 样品 | 结合胶含量趋势 |
|------|----------------|
| PS-SSBR/BR | 最低 |
| E7-SSBR/BR | 增加 |
| E15-SSBR/BR | 进一步增加 |
| E20-SSBR/BR | 接近 TESPD |
| E25-SSBR/BR | 超过 TESPD |
| TS-SSBR/BR | 参考 |

### 结合胶与分散性关系

结合胶含量反映填料-橡胶界面相互作用强度：
- 环氧化度越高，环氧基越多
- 更多环氧基与白炭黑反应
- 界面相互作用增强
- 结合胶含量增加
