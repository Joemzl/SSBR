# SSBR-038 综合档案

## 样本概述

SSBR-038 是一种采用烷基硫醇 (十二烷基硫醇, DT) 改性氧化石墨烯 (GO) 增强的 SSBR 复合材料。通过硫醇-烯点击化学反应，将 C12 烷基链接枝到 GO 表面，显著改善了 GO 在 SSBR 基体中的分散性和界面相容性。

## 改性策略

### 硫醇-烯点击反应

```
GO-C=C + HS-C₁₂H₂₅ → GO-CH₂-CH₂-S-C₁₂H₂₅
```

改性条件：
- 硫醇：十二烷基硫醇 (DT)
- 光引发剂：DMPA
- 反应方式：UV 光照

### 改性效果

| 指标 | GO | DT-GO | 改善 |
|------|-----|-------|------|
| 水接触角 | ~30° | ~90° | 疏水性提升 |
| 分散性 | 团聚严重 | 良好 | 显著改善 |

## 性能-结构关系

### 分散性改善机理

1. **表面能降低**: 烷基链使 GO 从亲水转为疏水
2. **相容性增强**: C12 烷基链与 SSBR 分子链化学相似
3. **团聚抑制**: 长链烷基的空间位阻效应

### 性能提升原因

1. **力学性能**: 良好分散增加了有效增强面积
2. **低滚动阻力**: 减少了填料-填料摩擦
3. **界面强度**: 改性增强了 GO-SSBR 界面作用

## 应用前景

- **绿色轮胎**: 低滚动阻力配方
- **高性能橡胶制品**: 需要高强度和良好耐磨性的应用
- **改性方法推广**: 硫醇-烯反应可扩展到其他纳米填料
