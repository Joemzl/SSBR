# SSBR-023 TEM 形貌解读

## 样本信息

- **官能化试剂**: 3-MPA (3-巯基丙酸)
- **核心官能团**: 羧基 (-COOH)
- **接枝工艺**: 固态原位接枝

## TEM 形貌分析

### 形貌特征

| 特征 | 描述 |
|------|------|
| 分散质量 | 良 |
| 团聚情况 | 较空白组明显减少 |
| 界面特征 | 羧基与白炭黑硅羟基形成氢键 |

### 核心发现

TEM 图像显示，经 3-MPA 官能化后，白炭黑在 SSBR 基体中的分散性明显改善，填料团聚现象减少，这与结合橡胶含量提升（67.1%）的结果一致。

### 机理分析

3-MPA 的羧基官能团与白炭黑表面的硅羟基形成强氢键作用，增强了填料-橡胶界面相互作用，从而改善了白炭黑的分散性。

### 分析结论

SSBR-023 的 TEM 形貌表明，固态原位接枝工艺能够有效改善白炭黑在 SSBR 基体中的分散性。
