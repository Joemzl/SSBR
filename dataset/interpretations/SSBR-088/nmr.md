# ¹H NMR 核磁共振解读：SSBR-088

> **样本性质**: 环氧化 SSBR (ESSBR)，8% 环氧化程度

## 一、基础信息

- **样本ID**: SSBR-088
- **样品名称**: 环氧化 SSBR (ESSBR)
- **官能化试剂**: H₂O₂ + 催化剂 CPC-PW4O16
- **环氧化程度**: 8%
- **苯乙烯含量**: 25 wt%
- **乙烯基含量**: 57 mol%
- **文献DOI**: 10.1016/j.polymer.2023.126082

## 二、官能化确认

### 特征峰归属

从 Fig.2 的 ¹H NMR 谱图可观察到：

| 化学位移 (ppm) | 归属 | 说明 |
|----------------|------|------|
| 2.7-2.9 | 环氧基氢 | 环氧化后新出现的特征峰 |
| 5.0-5.4 | =CH₂ (1,2-乙烯基) | 乙烯基双键氢，部分被环氧化消耗 |
| 5.4-5.6 | -CH=CH- (1,4-结构) | 主链内双键氢 |
| 6.5-7.2 | 苯环氢 | 苯乙烯单元芳香氢 |

### 环氧化程度

- **计算值**: 8%
- **计算方法**: 环氧基特征峰积分与主链峰积分的比值
- **反应选择性**: 主要发生在 1,2-乙烯基位点

### 核心发现

1. **环氧化成功**: 2.7-2.9 ppm 处出现环氧基特征峰
2. **适中转化率**: 8% 的环氧化程度保持了大部分双键
3. **结构完整性**: 主链结构保持完整
