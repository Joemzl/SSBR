## 二、填料分散状态

### 核心发现

1. **环氧基团的作用**: 环氧基团可与白炭黑表面的硅羟基反应，形成共价键
2. **分散改善**: 相比未环氧化 SSBR，分散性显著改善
3. **界面结合**: 共价键合提供了强界面结合

### 界面反应机理

```
白炭黑表面        环氧化 SSBR
   |                |
 Si-OH + CH₂-CH → Si-O-CH₂-CH-
           \O/              |
                           OH
```

环氧基团开环与硅羟基反应，形成 Si-O-C 共价键。

### 分析结论

环氧化 SSBR 通过环氧基团与白炭黑的共价反应，实现了优异的填料分散性和界面结合，这是绿色轮胎复合材料性能提升的关键。
