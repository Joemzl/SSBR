# SSBR-035 力学性能解读

## 样本信息

| 参数 | 数值 |
|------|------|
| 样本编号 | SSBR-035 |
| SSBR型号 | Buna VSL 5025-2HM（油充型） |
| 苯乙烯含量 | 25.0 wt% |
| 乙烯基含量 | 50.0 mol% |
| 填料体系 | RGO/SiO₂ 自组装纳米复合材料 |
| 基础胶配比 | SSBR/BR = 80/20 |

## 应力-应变曲线分析（Fig.9）

### 力学性能对比

文献研究了不同 RGO/SiO₂ 配比对复合材料力学性能的影响：

| 样品 | 填料组成 | 拉伸强度 (MPa) | 断裂伸长率 (%) | 300%定伸应力 (MPa) |
|------|----------|----------------|----------------|---------------------|
| 对照 | SiO₂ only | ~16 | ~450 | ~6.5 |
| RGO/SiO₂-1 | RGO/SiO₂ = 0.5/49.5 | ~18 | ~430 | ~7.5 |
| RGO/SiO₂-2 | RGO/SiO₂ = 1/49 | ~20 | ~420 | ~8.5 |
| RGO/SiO₂-3 | RGO/SiO₂ = 2/48 | ~21 | ~400 | ~9.0 |

### 关键发现

1. **RGO 增强效果**
   - 自组装 RGO/SiO₂ 纳米复合填料显著提升拉伸强度
   - 适量 RGO 可提高模量而不显著降低断裂伸长率
   - 最佳 RGO 含量约为 1-2 phr

2. **界面增强机制**
   - RGO 片层与 SiO₂ 纳米粒子形成核壳结构
   - 自组装过程改善填料分散性
   - Si-69 偶联剂增强填料-橡胶界面

3. **填料网络效应**
   - RGO 的二维结构有助于构建导电/增强网络
   - 填料-填料相互作用适度增强
   - 有效载荷传递路径

## 动态力学分析（DMA）

### Payne 效应（G' vs strain）

| 样品 | G'₀ (MPa) | G'∞ (MPa) | ΔG' (MPa) |
|------|-----------|-----------|-----------|
| SiO₂ only | ~4.5 | ~1.8 | ~2.7 |
| RGO/SiO₂-2 | ~5.2 | ~2.0 | ~3.2 |

- RGO/SiO₂ 体系 Payne 效应略有增加
- 填料网络增强但仍保持良好加工性

### 损耗因子（tan δ）

| 温度区间 | SiO₂ only | RGO/SiO₂-2 | 性能影响 |
|----------|-----------|------------|----------|
| 0°C (tan δ) | ~0.35 | ~0.38 | 湿抓地力↑ |
| 60°C (tan δ) | ~0.12 | ~0.09 | 滚动阻力↓ |

- 自组装 RGO/SiO₂ 改善"魔三角"平衡
- 低温损耗略增（湿抓地力改善）
- 高温损耗显著降低（滚动阻力降低）

## 结论

SSBR-035 采用自组装 RGO/SiO₂ 纳米复合填料技术，通过以下机制实现综合性能提升：
1. RGO 二维片层增强力学强度
2. 自组装改善填料分散
3. 优化的填料网络结构平衡动态性能

该技术为绿色轮胎胎面材料提供了新的填料改性策略。
