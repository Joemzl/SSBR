# SSBR-058 综合档案

## 样本概述

**SSBR-058** 采用**2-巯基乙醇 (ME)** 通过巯基-烯点击化学官能化 SSBR，引入羟基后通过 **oxa-Michael 反应**与丙烯酸酯进行交联，实现无硫硫化的绿色轮胎橡胶体系。

## 双重反应策略

### Step 1: 巯基-烯官能化

```
SSBR-CH=CH₂ + HS-CH₂-CH₂-OH → SSBR-CH₂-CH₂-S-CH₂-CH₂-OH
   乙烯基      2-巯基乙醇         羟基化 SSBR (mSSBR)
```

### Step 2: oxa-Michael 交联

```
mSSBR-OH + CH₂=CH-COOR → mSSBR-O-CH₂-CH₂-COOR
  羟基      丙烯酸酯            醚键交联
```

## 关键创新

### 1. 无硫硫化技术
- **传统问题**: 硫磺硫化产生有害气体，交联网络不均匀
- **本方案**: oxa-Michael 反应形成醚键交联
- **优势**: 环保、交联均匀、热稳定性好

### 2. 自增强白炭黑分散
- **机理**: 羟基与硅羟基形成氢键
- **效果**: 无需硅烷偶联剂即可改善分散
- **意义**: 简化工艺、降低成本

### 3. 模块化设计
- **官能化程度可调**: 通过 ME/SSBR 配比控制
- **交联密度可调**: 通过丙烯酸酯用量控制
- **性能定制**: 根据应用需求调整参数

## 性能分析

### 力学性能
- **高拉伸强度 (22.2 MPa)**: 界面增强 + 交联网络
- **良好伸长率 (530%)**: 交联密度适中
- **适中硬度 (64)**: 填料-橡胶体系平衡

### 热学性能
- **Tg = -25.8°C**: 官能化使 Tg 略有升高
- **热稳定性**: 醚键交联网络稳定

### 填料分散
- **分散性评级**: 良
- **无大团聚体**: 羟基-硅羟基相互作用有效
