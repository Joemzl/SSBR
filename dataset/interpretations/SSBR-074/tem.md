# SSBR-074 TEM 形貌解读

## 样本背景

SSBR-074 研究白炭黑填料网络与非线性粘弹性的关系。

## 填料网络形貌

### 数据来源
- **来源层级**: L3 (文献以流变研究为主)

### 填料网络模型

白炭黑在橡胶中形成的网络结构：

```
       [白炭黑聚集体]
           /  |  \
          /   |   \
[聚集体]—[橡胶桥]—[聚集体]
          \   |   /
           \  |  /
       [白炭黑聚集体]
```

### 网络层级

| 层级 | 尺度 | 结构单元 |
|------|------|----------|
| 一级 | 10-20 nm | 原生粒子 |
| 二级 | 50-200 nm | 聚集体 |
| 三级 | >1 μm | 团聚体网络 |

## 应变对网络的影响

### 网络破坏与恢复

| 应变状态 | 网络结构 | G' 值 |
|----------|----------|-------|
| 低应变 | 完整 | 高 |
| 中应变 | 部分破坏 | 中 |
| 高应变 | 大部分破坏 | 低 |
| 恢复 | 部分重建 | 中等 |

### 分子机理

```
低应变:
[白炭黑]═══[橡胶桥]═══[白炭黑] (弹性变形)

高应变:
[白炭黑]   [橡胶桥]   [白炭黑] (网络断裂)
```

## 与 Payne 效应的关联

### Payne 效应的微观起源

1. **填料-填料接触**: 主要贡献
2. **填料-橡胶界面**: 次要贡献
3. **链段解吸附**: 滞后贡献

## 数据限制说明

文献主要关注流变学研究，TEM 形貌数据未详细报道。
