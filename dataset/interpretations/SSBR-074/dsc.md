# SSBR-074 DSC 热分析解读

## 样本背景

SSBR-074 研究白炭黑/SSBR 的非线性流变行为，热学性能作为辅助信息。

## 玻璃化转变温度

### 数据来源
- **来源层级**: L3 (基于材料体系估算)
- **Tg**: 约 -30°C

### 填料对 Tg 的影响

白炭黑填充对 Tg 的影响：

1. **界面约束**: 填料表面约束橡胶链段
2. **限域效应**: 纳米尺度限域可能改变 Tg
3. **整体影响**: 通常略微升高 Tg (0-5°C)

## 与流变性能的关联

### 温度-频率等效

玻璃化转变与流变行为的关系：

| 温度范围 | 流变特性 |
|----------|----------|
| T << Tg | 玻璃态，高模量 |
| T ≈ Tg | 转变区，tan δ 峰 |
| T >> Tg | 橡胶态，低模量 |

### WLF 方程

Williams-Landel-Ferry 方程描述时-温等效：

```
log(aT) = -C1(T-Tr) / (C2 + T - Tr)
```

其中 Tr 通常取 Tg + 50°C
