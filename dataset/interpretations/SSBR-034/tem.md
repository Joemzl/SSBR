# SSBR-034 表面形貌解读

## 测试概述

本样本 SSBR-034 的研究重点是 TMPMP/SBR 超疏水涂层的表面微观结构。与传统的填料分散性研究不同，本文献使用 SEM 和接触角测量来表征涂层的超疏水性能。

## 超疏水性能

### 接触角测试

根据文献报道：
- **静态接触角**: 161°
- **滚动角**: 2.5°
- **判定标准**: 接触角 > 150° 且滚动角 < 10° 即为超疏水

### 表面能分析
- 超疏水性源于**低表面能 + 微纳粗糙结构**的协同作用
- SBR 本身具有较低的表面能
- TMPMP 交联后形成的微观结构进一步增强疏水性

## SEM 形貌观察

### 微观结构特征
- **花瓣状结构**: UV 固化过程中形成的特殊微纳形貌
- **多尺度粗糙度**: 微米级和纳米级结构的复合
- **均匀分布**: 涂层表面结构分布均匀

### 形成机理
1. UV 固化过程中 TMPMP 与 SBR 快速交联
2. 相分离导致表面形成微纳结构
3. 溶剂挥发进一步塑造表面形貌

## 涂层耐久性

文献报道该超疏水涂层具有良好的耐久性：
- **机械稳定性**: 经受多次摩擦后仍保持超疏水性
- **化学稳定性**: 对酸碱溶液有一定耐受性
- **紫外稳定性**: UV 固化体系本身具有光稳定性

## 应用前景

TMPMP/SBR 超疏水涂层可应用于：
- 自清洁表面
- 防腐蚀涂层
- 油水分离膜
- 防冰涂层

## 备注

本样本不涉及填料体系，无传统意义的 TEM 分散性评价。超疏水涂层的研究方向与橡胶复合材料改性有所不同。
