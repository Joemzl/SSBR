# SSBR-034 核磁共振解读

## 测试概述

本样本 SSBR-034 使用 TMPMP 作为交联剂与 SBR 进行巯基-烯反应。文献中未提供详细的 NMR 表征数据。

## 反应配比

根据文献报道的涂层配方：
- **SBR 基体**: 作为成膜物质
- **TMPMP 交联剂**: 与 SBR 中的双键反应形成交联网络
- **反应方式**: UV 引发的巯基-烯自由基加成

## TMPMP 结构特征

TMPMP（三羟甲基丙烷三(3-巯基丙酸)酯）的结构：
- **分子式**: C₁₅H₂₆O₆S₃
- **官能团**: 三个巯基（-SH）
- **SMILES**: SCCC(=O)OCC(CC)(COC(=O)CCS)OC(=O)CCS

### NMR 特征峰（理论）
- **δ 1.3-1.5 ppm**: -SH（巯基氢）
- **δ 2.6-2.8 ppm**: -CH₂-S-（与硫相连的亚甲基）
- **δ 2.4-2.6 ppm**: -CH₂-CO-（与羰基相连的亚甲基）
- **δ 4.0-4.2 ppm**: -O-CH₂-（酯键亚甲基）

## 反应监测

巯基-烯反应可通过以下方式监测：
1. **巯基峰消失**: -SH 峰强度下降表示反应进行
2. **双键峰消失**: SBR 乙烯基双键信号减弱
3. **新峰出现**: 形成 C-S 键后产生新的化学位移

## 备注

本研究重点不在于官能化程度的精确表征，而是通过控制 TMPMP/SBR 配比获得最优的超疏水性能。
