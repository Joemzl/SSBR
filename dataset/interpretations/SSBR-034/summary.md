# SSBR-034 综合档案

## 样本概述

**SSBR-034** 采用**三羟甲基丙烷三(3-巯基丙酸)酯 (TMPMP)** 作为交联剂，通过巯基-烯点击化学与 SBR 进行 UV 固化反应，制备超疏水涂层。

## 官能化策略

### 反应机理
TMPMP 是一种三官能团巯基化合物，其三个巯基可与 SBR 分子链上的乙烯基双键发生自由基加成反应：

```
3 × (R-SH) + 3 × (CH₂=CH-) → 交联网络
```

UV 光引发形成巯基自由基，随后与烯烃双键加成，形成稳定的硫醚键（C-S-C）。

### 交联特点
- **三官能团**: 每个 TMPMP 分子可连接三条 SBR 链
- **高效交联**: UV 固化快速完成
- **网络结构**: 形成三维交联网络

## 核心发现

### 超疏水性能
该研究成功制备了具有优异超疏水性能的 TMPMP/SBR 涂层：
- **静态接触角**: 161° (> 150° 超疏水阈值)
- **滚动角**: 2.5° (< 10° 超疏水阈值)

### 表面结构
SEM 观察显示涂层表面具有**花瓣状微纳结构**：
- 微米级与纳米级结构的复合
- 多尺度粗糙度是超疏水性的结构基础
- UV 固化过程中的相分离形成特殊形貌

### 耐久性
- 机械摩擦后仍保持超疏水性
- 对酸碱环境有一定耐受性

## 创新亮点

1. **简便工艺**: UV 快速固化，室温操作
2. **环保**: 无需高温处理，能耗低
3. **通用性**: 可应用于多种基材

## 应用方向

| 应用领域 | 优势 |
|---------|------|
| 自清洁表面 | 水滴滚落带走污染物 |
| 防腐蚀涂层 | 阻隔水分渗透 |
| 油水分离 | 选择性润湿 |
| 防冰涂层 | 降低冰附着力 |

## 研究特色

本样本的研究方向是**超疏水涂层技术**，与传统的 SSBR 橡胶复合材料改性研究有所不同：
- 不涉及填料分散
- 不关注传统力学性能
- 重点研究表面润湿性和涂层耐久性

## 相关技术

巯基-烯点击化学在橡胶改性中的应用：
- 高效、选择性好
- 可在室温/UV 条件下进行
- 产物结构明确
