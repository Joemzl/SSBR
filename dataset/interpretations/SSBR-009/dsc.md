# SSBR-009 DSC 热分析解读

## 样本信息

| 属性 | 值 |
|------|-----|
| 样本编号 | SSBR-009 |
| 官能团 | 无（空白未官能化 SSBR） |
| 文献来源 | Zhang_2018 |
| 测试方法 | DSC (TA Q20) |

## 测试条件

| 参数 | 设置 |
|------|------|
| 仪器 | TA Q20 |
| 温度范围 | 加热至 80℃ 消除热历史，冷却至 -80℃ |
| 升温速率 | 10℃/min |
| 测量方式 | 第二次升温扫描 |

## DSC 测试结果

### 玻璃化转变温度

| 样本 | Tg (℃) | 羟基含量 (mmol/100g) |
|------|--------|---------------------|
| SSBR（未改性） | -26.1 | 0 |
| 参考：OS2.9 | -25.0 | 24 |
| 参考：OS7.8 | -21.3 | 64 |
| 参考：OS10.1 | -17.7 | 83 |

### 热行为特征

- **单一玻璃化转变**: 仅观察到一个 Tg，表明 SSBR 的无定形特性
- **低温性能**: Tg = -26.1℃，远低于室温，具有良好的低温柔顺性
- **相态**: 无结晶峰，为典型的无定形聚合物

## DSC 曲线解读

### 1. 玻璃化转变特性

SSBR-009 作为未官能化空白样本：
- **Tg = -26.1℃** 是该系列中最低的
- 分子链运动不受氢键约束
- 链段运动自由度最高

### 2. 与官能化样本对比

官能化导致 Tg 升高的机理：
- 羟基基团间形成氢键
- 氢键抑制链段运动
- Tg 随羟基含量增加而线性升高

| 羟基含量变化 | Tg 变化 |
|-------------|--------|
| 0 → 24 mmol/100g | -26.1 → -25.0℃ (+1.1℃) |
| 0 → 64 mmol/100g | -26.1 → -21.3℃ (+4.8℃) |
| 0 → 83 mmol/100g | -26.1 → -17.7℃ (+8.4℃) |

### 3. 低温性能评估

- **冷耐受性**: 所有样本的 Tg 均远低于室温
- **使用温度范围**: 适合在 -20℃ 以上环境使用
- **轮胎应用**: 满足冬季轮胎的低温柔顺性要求

## 轮胎性能相关性

| Tg 范围 | 性能预期 |
|---------|----------|
| -26.1℃ | 优异的低温性能，良好的弹性恢复 |
| 与抗湿滑相关性 | Tg 越高，0℃ 附近 tan δ 越大，抗湿滑越好 |
| 与滚动阻力相关性 | Tg 越高，60℃ tan δ 可能越大，滚阻可能增加 |

## 结论

1. SSBR-009 具有该系列中**最低的 Tg**（-26.1℃）
2. 未官能化状态提供了**最佳的低温柔顺性**
3. 作为对照样本，验证了**羟基含量与 Tg 的正相关关系**
