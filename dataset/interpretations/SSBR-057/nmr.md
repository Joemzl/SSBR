# SSBR-057 NMR 解读

## 低场 NMR 分析（Fig.1）

### 研究方法

本研究使用紧凑型低场 NMR 光谱仪（~20 MHz）进行生胶质量控制。

| 设备参数 | 数值 |
|----------|------|
| 场强 | ~0.5 T |
| 频率 | ~20 MHz |
| 样品量 | 小量 (~10 mL) |
| 测量时间 | 几分钟 |

### 测量类型

| 测量 | 信息 | 应用 |
|------|------|------|
| ¹H NMR 谱 | 化学组成 | 定性分析 |
| T₂ 弛豫 | 链段运动 | 分子量估算 |
| T₁ 弛豫 | 自旋-晶格 | 交联程度 |

### 化学计量学分析

结合多变量统计方法：

| 方法 | 用途 |
|------|------|
| PCA | 样品分类 |
| PLS | 定量预测 |
| SIMCA | 质量判定 |

### 关键发现

1. **快速质量控制**
   - 测量时间 < 5 分钟
   - 无需复杂样品前处理
   - 可在生产线在线应用

2. **多参数预测**
   - 门尼粘度预测
   - 苯乙烯含量预测
   - 乙烯基含量预测

3. **实用性验证**
   - 多种商业橡胶样品测试
   - 预测精度满足工业要求
   - 可替代部分传统检测
