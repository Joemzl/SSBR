## 分散改善机理

### 极性桥梁作用

```
未改性：填料-填料主导
    
    SiO₂-Si-OH···HO-Si-SiO₂
    (白炭黑自聚集)
    
改性后：填料-橡胶-填料

    SiO₂-Si-OH···HOOC-SSBR···HOOC-SSBR···HO-Si-SiO₂
                  ↑
            羧基作为桥梁
```

### 氢键相互作用

| 相互作用 | 类型 |
|----------|------|
| -COOH···HO-Si- | 氢键 |
| 强度 | 中等 |
| 稳定性 | 良好 |

```
    白炭黑表面
    ═══════════
        ↑ Si-OH
        │
      氢键

    ════════════
    MSSBR 分子链
    ────────────
    结合胶层（更厚）
```

## 增强效率

### RE (Reinforcing Efficiency)

| 样本 | RE 值 | 增强效率 |
|------|-------|---------|
| Sample 1 | 基准 | 参考 |
| Sample 2 | 略增加 | 改善 |

公式：
$$RE = \frac{(M_H - M_L)_{filled} - (M_H - M_L)_{gum}}{(M_H - M_L)_{gum}}$$

## 结论

1. **初步分散改善**: 0.2 phr MPA 即产生效果
2. **结合胶增加**: +3.1%
3. **L 值降低**: 分散性提高
4. **改善有限**: 需要更高用量达到最优
