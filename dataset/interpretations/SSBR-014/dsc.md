## DMA 曲线解读

### 1. Tg 轻微升高

Tg 从 -8.0℃ 升至 -7.8℃（+0.2℃）：

| 因素 | 影响 |
|------|------|
| 羧基引入 | 增加分子间作用力 |
| 填料相互作用 | 限制链段运动 |
| 氢键形成 | 羧基-硅羟基氢键 |

### 2. tan δmax 增加

tan δmax 从 1.0460 增至 1.1257（+7.6%）：

```
tan δmax 增加机理：

改善分散 → 聚合物有效体积↑ → tan δmax↑

未改性：
  [填料团聚] → 聚合物被"排斥" → 有效体积↓

改性后：
  [均匀分散] → 聚合物充分参与 → 有效体积↑
```

### 3. 抗湿滑性改善

tan δ (0℃) 从 0.7596 增至 0.8190（+7.8%）：

| 机理 | 解释 |
|------|------|
| 分散改善 | 更多聚合物参与能量耗散 |
| 界面增强 | 橡胶-填料相互作用增强 |
| Tg 效应 | Tg 略微升高 |

### 4. 滚动阻力降低

tan δ (60℃) 从 0.0913 降至 0.0818（-10.4%）：

| 机理 | 解释 |
|------|------|
| 填料网络变化 | 填料-填料摩擦减少 |
| 界面改善 | 能量耗散更有效 |
| 结合胶增加 | 更多"bound rubber"减少滑移 |
