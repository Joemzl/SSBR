## NMR 谱图解读

### 1. 接枝反应确认

2.75 ppm 新峰的出现确认了 MPA 成功接枝：

```
接枝反应：

SSBR-CH=CH₂ + HS-CH₂-CH₂-COOH
       ↓ 硫醇-烯反应
SSBR-CH₂-CH₂-S-CH₂-CH₂-COOH
              ↑
           2.75 ppm (-SCH₂-)
```

### 2. 乙烯基消耗

| 观察 | 结果 |
|------|------|
| 1,2-PB 降低 | 47.3 → 46.3 mol% |
| 1,4-PB | 不变 (36.7 mol%) |
| 接枝选择性 | 仅乙烯基参与 |

### 3. 接枝率计算

| 参数 | 值 |
|------|-----|
| 投料 MPA | 0.2 phr |
| 实际接枝率 | 1.7 mol% |

## 接枝效率分析

### 固相原位接枝 (SPGiS) 特点

| 特点 | 描述 |
|------|------|
| 反应条件 | 密炼机中，90℃，3 min |
| 无溶剂 | 绿色环保 |
| 效率 | 高转化率 |
| 操作 | 简单，可规模化 |

### 与溶液法对比

| 对比项 | SPGiS | 溶液法 |
|--------|-------|--------|
| 能耗 | 低 | 高 |
| 溶剂 | 无 | 需要 |
| 效率 | 高 | 中等 |
| 工业化 | 容易 | 复杂 |

## 凝胶含量

| 样本 | 凝胶含量 |
|------|---------|
| SSBR | 基准 |
| MSSBR (0.2 phr) | 略增加 |

> 低用量 MPA 不会导致严重的凝胶化

## 结论

1. **接枝成功**: 2.75 ppm 新峰确认
2. **接枝率 1.7%**: 乙烯基消耗约 1 mol%
3. **选择性反应**: 仅乙烯基参与
4. **分子量稳定**: 无主链断裂
