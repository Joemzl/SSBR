## 性能解读

### 1. 硫化时间缩短

tc₉₀ 从 29.3 min 降至 26.3 min（-10.2%）

| 原因 | 解释 |
|------|------|
| 极性增加 | 羧基改善橡胶-白炭黑相容性 |
| 促进剂释放 | 白炭黑吸附的促进剂减少 |
| ZnO 可用性 | 更多 ZnO 参与活化 |

### 2. 扭矩差增加

MH - ML 增加 1.04 dN·m：

| 因素 | 贡献 |
|------|------|
| 化学交联 | 硫化网络 |
| 物理交联 | 羧基与白炭黑氢键 |
| 填料网络 | 填料-橡胶-填料替代填料-填料 |

### 3. 结合胶提升

结合胶从 52.6% 增至 55.7%：

```
结合胶形成示意：

    白炭黑表面
    ═══════════
        ↑
      氢键
        ↓
    SSBR-COOH
    (改性橡胶)
        
羧基与硅羟基形成氢键
→ 橡胶更牢固吸附在填料表面
→ 结合胶增加
```

### 4. 填料分散改善

| Q_f/Q_g | 降低 |

## 关键发现

1. **初步极性改善**: 0.2 phr MPA 即可产生效果
2. **硫化加速**: tc₉₀ 降低 10%
3. **结合胶增加**: +3.1%
