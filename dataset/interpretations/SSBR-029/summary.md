# SSBR-029 综合档案

## 样本概述

SSBR-029 来自中国研究团队关于乙烯基和苯基含量对 HVBR 和 SSBR 物理及动态力学性能影响的研究。本文献系统比较了两类橡胶的性能差异。

## 研究亮点

### 1. SSBR vs HVBR 比较

| 特性 | SSBR | HVBR |
|------|------|------|
| 苯基含量 | 有（苯乙烯）| 无 |
| 乙烯基含量 | 中等 | 高 |
| Tg | 较高 | 较低 |
| 滞后损失 | 中等 | 低 |
| 湿地抓地力 | 好 | 一般 |

### 2. 分子设计策略

本研究为橡胶分子设计提供指导：
- 根据目标性能选择合适的橡胶类型
- 通过调节乙烯基/苯基比例优化性能
- 可考虑 SSBR/HVBR 并用

### 3. 轮胎应用

- SSBR 适合湿地抓地力要求高的应用
- HVBR 适合低滚阻要求的应用
- 并用可实现性能平衡
