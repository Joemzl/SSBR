# SSBR-068 TEM 形貌解读

## 样本背景

SSBR-068 研究膨胀石墨在 SSBR 基体中的分散，以及 XSBR 增容剂的作用。

## 形貌表征

### 数据来源
- **来源层级**: L1 (文献形貌分析)
- **表征方法**: TEM/SEM

### EG 分散状态

文献描述的形貌特征：

1. **无增容剂**: EG 团聚明显，分散不均
2. **有 XSBR**: EG 分散改善，片层分布更均匀
3. **与炭黑复配**: 形成协同填料网络

## 膨胀石墨形貌

### EG 的微观结构

```
原始石墨 → 插层 → 膨胀 → 膨胀石墨
    ↓
 层状结构
    ↓
 蠕虫状/片状
```

### 在橡胶中的形态

| 条件 | 形态 | 效果 |
|------|------|------|
| 无增容 | 大片团聚 | 补强差 |
| 有增容 | 小片分散 | 补强好 |
| 复配炭黑 | 互补网络 | 最优 |

## XSBR 增容作用可视化

### 界面改善

```
[EG 片层]
    |← XSBR 界面层 →|
         |
    [SSBR 基体]
```

### 分散对比

无 XSBR 时：
- EG 片层堆叠
- 大尺寸团聚体
- 界面脱粘明显

有 XSBR 时：
- EG 分散较均匀
- 团聚体尺寸减小
- 界面结合改善

## 炭黑复配形貌

### 双填料网络

```
[EG]——[CB]——[EG]——[CB]
  |      |      |      |
[SSBR 基体连续相]
```

### 协同效应

1. **导电网络**: EG 和 CB 共同形成
2. **补强网络**: CB 弥补 EG 补强不足
3. **加工优化**: 改善混炼效率

## 综合评价

XSBR 增容剂有效改善了膨胀石墨在 SSBR 中的分散，与炭黑复配可进一步优化复合材料性能。
