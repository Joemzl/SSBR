# SSBR-053 力学性能解读

## 样本信息

| 参数 | 数值 |
|------|------|
| 样本编号 | SSBR-053 |
| SSBR型号 | Buna VSL 5025-2HM |
| 苯乙烯含量 | 25.0 wt% |
| 乙烯基含量 | 50.0 mol% |
| 填料体系 | SiO₂/CB/纳米粘土 |
| 并用胶 | SSBR/LPI (液体聚异戊二烯) |

## 研究背景

本研究探索纳米填料几何形状与剪切流动对 SSBR/LPI/填料三元体系形貌演变的协同效应，研究不同形状填料（球形 SiO₂、层状粘土、颗粒状炭黑）的分散与分布行为。

## 流变性能分析（Fig.13）

### 稳态剪切粘度

| 样品 | 填料类型 | 低剪切粘度 | 剪切稀化 |
|------|----------|------------|----------|
| SSBR/LPI | 无填料 | 最低 | 弱 |
| +SiO₂ | 球形 | 中等 | 中等 |
| +Clay | 层状 | 较高 | 强 |
| +CB | 颗粒状 | 较高 | 强 |

### 关键发现

1. **填料几何效应**
   - 层状粘土最显著增加粘度
   - 球形 SiO₂ 增粘效应较温和
   - 填料形状影响流变行为

2. **剪切稀化行为**
   - 所有填充体系呈剪切稀化
   - 层状填料稀化最显著
   - 与填料取向相关

3. **并用胶相容性**
   - LPI 作为增塑剂/相容剂
   - 影响填料分布于相界面
   - 形貌演变依赖填料类型

## 力学性能

本研究侧重流变与形貌，静态力学数据有限：

| 特性 | 趋势 |
|------|------|
| 模量 | 随填料增加↑ |
| 加工性 | 依赖填料类型 |

## 结论

SSBR-053 研究了填料几何形状对并用胶流变和形貌的影响：
- 填料形状决定增粘效果
- 剪切流动影响形貌演变
- 为多相体系设计提供指导
