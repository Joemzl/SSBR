# SSBR-056 力学性能解读

## 样本信息

| 参数 | 数值 |
|------|------|
| 样本编号 | SSBR-056 |
| SSBR型号 | Buna VSL 5025-2HM |
| 苯乙烯含量 | 25.0 wt% |
| 乙烯基含量 | 50.0 mol% |
| 应用场景 | 轮胎生产 |

## 研究背景

本研究是 SSBR-054 的续篇，提出增强橡胶动态力学行为的叠加方法，建立更完善的本构模型用于轮胎材料预测。

## 动态力学分析（Fig.1）

### 主曲线构建

| 参数 | 方法 | 结果 |
|------|------|------|
| 参考温度 | Tg + 50°C | ~20°C |
| 频率范围 | 0.01-100 Hz | 10⁻⁴-10¹² Hz (叠加后) |
| 移位因子 | WLF 方程 | 良好拟合 |

### 储能模量 E'

| 频率区 | E' 特征 | 物理解释 |
|--------|---------|----------|
| 低频 | 橡胶平台 | ~1-10 MPa |
| 转变区 | 快速上升 | Tg 附近 |
| 高频 | 玻璃平台 | ~1 GPa |

### 损耗因子 tan δ

| 频率 | tan δ | 应用关联 |
|------|-------|----------|
| ~10⁻² Hz | 高温行为 | 滚动阻力 |
| ~10⁴ Hz | Tg 区 | 抓地力 |
| ~10⁸ Hz | 玻璃态 | 耐磨性 |

### 叠加原理验证

1. **时温叠加 (TTS)**
   - 不同温度数据可叠加
   - WLF 方程描述移位因子
   - 扩展频率范围

2. **应变叠加**
   - 考虑 Payne 效应
   - 应变依赖性建模
   - 非线性行为捕获

3. **填料叠加**
   - 不同填料含量
   - 增强因子方法
   - 统一描述框架

## 结论

SSBR-056 验证了增强橡胶的叠加方法：
- 时温叠加有效
- 应变效应可建模
- 为轮胎设计提供预测工具
