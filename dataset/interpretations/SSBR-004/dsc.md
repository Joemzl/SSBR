## 性能解读

### Tg 变化分析

SSBR-004（硅烷官能化）的 Tg 为 -5.5℃，在系列样品中 **Tg 最高**：

| 样品 | 官能团 | Tg (℃) | ΔTg vs 空白 | 界面结合类型 |
|------|--------|--------|-------------|--------------|
| SSBR-001 | 无 | -9.0 | 0 | 无 |
| SSBR-002 | -OH | -8.5 | +0.5 | 氢键 |
| SSBR-003 | -COOH | -7.0 | +2.0 | 强氢键 |
| SSBR-004 | -Si(OEt)₃ | **-5.5** | **+3.5** | **共价键** |

**Tg 升高最多的原因**：

1. **共价界面结合**: 
   - 硅烷基团与白炭黑形成 Si-O-Si 共价键
   - 共价键强度远高于氢键
   - 分子链在界面处运动受限最严重

2. **高效偶联**: 
   - 硅烷官能化实现真正的化学桥接
   - 界面处形成交联网络
   - 有效交联密度最高

3. **界面约束效应**: 
   - 共价键合的分子链段运动自由度最低
   - 相当于增加了交联点

### Tg 与界面结合强度的关系

系列样品展示了 Tg 与界面结合强度的正相关关系：

```
界面结合强度: 无 < 氢键(-OH) < 强氢键(-COOH) < 共价键(-Si-)
Tg 升高程度:  0   <  0.5℃   <    2.0℃     <    3.5℃
```

### 对轮胎性能的影响

Tg 升高 3.5℃对轮胎性能的影响分析：

| 性能指标 | 影响 | 说明 |
|----------|------|------|
| 滚动阻力 | 略增加 | Tg 仍低于 0℃，影响可控 |
| 湿抓地力 | 明显提升 | Tg 升高有利于湿抓地力 |
| 冰面抓地 | 潜在提升 | 接近 0℃ 区域性能改善 |
| 低温性能 | 需关注 | 极寒环境（<-30℃）需评估 |

### 性能权衡分析

硅烷官能化带来的 Tg 升高是性能优化的结果：
- **力学性能大幅提升**: 抵消 Tg 升高的不利影响
- **抓地性能改善**: Tg 升高有利于抓地力
- **滚阻可控**: Tg 仍在合理范围内
