# SSBR-064 综合档案

## 研究概述

本研究采用对苯二胺 (PPD) 改性氧化石墨烯 (GO) 增强 SSBR，实现了抗老化、低滚动阻力和高抗湿滑性能的多功能改性。

## 官能化策略

### PPD 改性 GO 合成

```
GO + PPD → GO-PPD
(氧化石墨烯)  (对苯二胺)  (改性GO)

反应类型：
1. GO-COOH + H2N-Ar-NH2 → GO-CONH-Ar-NH2 (酰胺化)
2. GO-环氧 + H2N-Ar-NH2 → GO-CH(OH)-CH2-NH-Ar-NH2 (开环)
```

### 双重功能设计

1. **改善分散**: PPD 改性增强 GO 与 SSBR 相容性
2. **抗氧化**: PPD 是经典的橡胶抗氧剂

## 技术亮点

### 突破性能三角

传统轮胎材料面临滚动阻力-抗湿滑-耐磨性的三角矛盾，PPD-GO 策略实现：

| 性能 | 传统方案 | PPD-GO 方案 |
|------|----------|-------------|
| 滚动阻力 | 基准 | 降低 |
| 抗湿滑 | 基准 | 提高 |
| 耐磨性 | 基准 | 保持 |
| 抗老化 | 基准 | 显著提高 |

### 抗老化机理

```
PPD 捕获自由基: PPD + R· → PPD· (稳定)
GO 物理阻隔: 减缓 O2 渗透
协同效应: 化学+物理双重保护
```

## 应用前景

PPD 改性 GO/SSBR 复合材料适用于：

1. **长寿命轮胎**: 优异的抗老化性能延长使用寿命
2. **节能轮胎**: 低滚动阻力降低油耗
3. **安全轮胎**: 高抗湿滑性能提升安全性
