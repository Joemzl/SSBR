## PPD 改性 GO 结构

### PPD 与 GO 的反应

```
GO-COOH + H2N-C6H4-NH2 → GO-CONH-C6H4-NH2 + H2O
(氧化石墨烯)  (对苯二胺)    (PPD改性GO)
```

### 官能团特征

| 官能团 | 来源 | 作用 |
|--------|------|------|
| -CONH- | PPD-GO 酰胺键 | 稳定连接 |
| -NH2 | PPD 游离氨基 | 与橡胶相互作用 |
| -OH | GO 残留羟基 | 亲水性 |

## 改性效果

PPD 改性 GO 的结构优势：

1. **双氨基**: PPD 提供两个氨基，一个与 GO 反应，一个与橡胶相互作用
2. **π-π 相互作用**: 苯环与 GO 的π电子云相互作用
3. **抗氧化功能**: PPD 本身是抗氧剂，提供原位保护
