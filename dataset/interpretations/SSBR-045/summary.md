# SSBR-045 综合档案

## 样本概述

SSBR-045 是一种标准的白炭黑/SSBR 复合材料，文献主要用于系统研究白炭黑填充橡胶的应力松弛行为和填料网络动力学。该研究为理解绿色轮胎材料的动态性能提供了重要的基础理论支撑。

## 研究重点

### 应力松弛研究意义

应力松弛是评价橡胶材料长期性能的重要指标：
- 影响轮胎的形变恢复
- 与滚动阻力相关
- 反映填料网络的稳定性

### 研究方法

| 方法 | 目的 |
|------|------|
| 应变扫描 | Payne 效应表征 |
| 应力松弛 | 网络动力学研究 |
| 温度变化 | 活化能计算 |
| 多次循环 | 网络可逆性验证 |

## 科学发现

### 双松弛机理

文献提出了白炭黑/SSBR 体系的双松弛模型：

1. **快速松弛 (τ₁)**
   - 时间尺度: ~50 秒
   - 来源: 橡胶分子链的构象重排
   - 特点: 温度敏感性高

2. **慢速松弛 (τ₂)**
   - 时间尺度: ~500 秒
   - 来源: 填料网络/聚集体重排
   - 特点: 应变历史依赖

### 填料网络特性

| 特性 | 描述 |
|------|------|
| 可逆性 | 网络可破坏并重建 |
| 时间尺度 | 重建需要数分钟 |
| 应变依赖 | 大应变加速破坏 |
| 温度依赖 | 高温加速重组 |

## 性能-结构关系

### Payne 效应与应力松弛

- Payne 效应反映了填料网络的强度
- 应力松弛反映了网络的动态特性
- 两者共同描述了填料网络的完整图像

### 对绿色轮胎设计的启示

1. **降低 ΔG'**: 减少填料团聚，改善分散
2. **加速松弛**: 提高网络重建速率
3. **平衡设计**: 既要强度又要恢复性
