# SSBR-067 综合档案

## 研究概述

本研究系统研究了星型 SSBR 的结构特点及其与白炭黑/炭黑双填料体系共凝聚复合材料的形貌和力学性能。

## 星型 SSBR 结构

### 合成策略

```
活性阴离子聚合:
n-BuLi + 苯乙烯/丁二烯 → SSBR-Li⁺

偶联反应:
4 SSBR-Li⁺ + SiCl4 → (SSBR)4Si + 4 LiCl
```

### 结构特点

| 特性 | 星型 SSBR | 线型 SSBR |
|------|-----------|-----------|
| 拓扑结构 | 星型 (4-6 臂) | 线性 |
| 溶液黏度 | 低 | 高 |
| 链端数量 | 多 | 少 (2 个) |
| 加工性 | 好 | 一般 |

## 双填料体系

### 共凝聚工艺

```
乳液共凝聚:
SSBR 乳液 + SiO2 分散液 + CB 分散液 → 共凝聚 → 复合材料
```

### 双填料协同效应

| 填料 | 作用 | 性能贡献 |
|------|------|----------|
| 白炭黑 | 补强、改善抗湿滑 | 力学性能、抗湿滑 |
| 炭黑 | 补强、改善耐磨 | 力学性能、耐磨性 |

## 技术亮点

### 星型结构优势

1. **加工性**: 低溶液黏度便于加工
2. **分散性**: 更好的填料分散
3. **官能化**: 更多链端可用于官能化

### 共凝聚工艺优势

1. **分散均匀**: 液相分散优于干法混炼
2. **能耗低**: 减少机械剪切
3. **可控性**: 精确控制填料比例

## 应用前景

星型 SSBR/双填料体系适用于：

1. **高性能轮胎**: 综合优化各项性能
2. **工业橡胶制品**: 良好的加工性和力学性能
3. **特种橡胶应用**: 可进一步官能化
