# SSBR-067 NMR 结构解读

## 样本背景

SSBR-067 是星型溶聚丁苯橡胶，通过偶联剂将多条线型 SSBR 臂连接形成星型结构。

## 分子结构

### 数据来源
- **来源层级**: L3 (文献未详细报道)

### 星型结构

```
合成路线:
SSBR-Li⁺ + SiCl4 → (SSBR)4-Si (四臂星型)

或使用其他多官能偶联剂形成 4-6 臂星型结构
```

### 结构特点

| 参数 | 特点 |
|------|------|
| 拓扑结构 | 星型 (4-6 臂) |
| 臂结构 | 苯乙烯-丁二烯无规共聚物 |
| 核心 | 偶联剂残基 |

## NMR 分析要点

星型 SSBR 的 NMR 表征：

1. **苯乙烯单元**: δ 6.5-7.5 ppm (芳环)
2. **丁二烯单元**: 
   - 1,4-加成: δ 5.3-5.5 ppm
   - 1,2-加成: δ 4.8-5.0 ppm
3. **核心区域**: 偶联剂相关信号

## 星型结构验证

验证星型结构的方法：

1. **GPC**: 分子量分布和结构因子
2. **光散射**: 流体力学半径
3. **溶液黏度**: 与线型对比

## 星型 vs 线型 SSBR

| 特性 | 星型 | 线型 |
|------|------|------|
| 溶液黏度 | 低 | 高 |
| 链端数量 | 多 | 少 |
| 加工性 | 好 | 一般 |
| 混炼分散 | 易 | 难 |
