# ¹H NMR 核磁共振解读：SSBR-018

## 一、官能化确认

### 结构特征

α-SSBR 是通过以下路线合成的（Fig.1）：
1. 以 DPE-(NMe₂)₂-Li⁺ 作为引发剂引发聚合
2. 氨基官能团位于聚合物链端（靠近活性中心）

### 合成参数

| 参数 | α-SSBR |
|------|--------|
| 引发体系 | DPE-(NMe₂)₂-Li⁺ |
| 溶剂 | 正己烷 |
| 聚合温度 | 50°C |
| TMEDA/Li 比 | 4 |
| 终止剂 | 异丙醇 |

### 官能化程度

- **DPE 单元含量**: 0.09 wt%（由 ¹H NMR 计算）
- **端基封装效率**: 83%
- **计算方法**: Supporting Information Eq. S(1)-(5)

### 微观结构

| 结构单元 | 含量 | 计算依据 |
|----------|------|----------|
| 苯乙烯 | 27.8 wt% | ¹H NMR |
| 1,2-乙烯基（丁二烯） | 64.3 wt% | ¹H NMR |
| 嵌段度 | 2.6% | ¹H NMR |

### 核心发现

1. **成功官能化**：NMR 谱图确认了 DPE-(NMe₂)₂ 成功引入 SSBR 链端
2. **窄分布**：PDI = 1.15，表明活性阴离子聚合可控性好
3. **高乙烯基含量**：64.3% 的乙烯基含量有利于与白炭黑的界面反应
