# SSBR-076 NMR/FT-IR 结构表征解读

## 样本概述

SSBR-076 使用 m-CPBA 进行环氧化，其结构表征方法与 SSBR-062 相同。

## ¹H NMR 特征

### 预期特征峰

| 化学位移 (ppm) | 归属 |
|----------------|------|
| 4.90 | 1,2-乙烯基 (基本不变) |
| 5.25 | 1,4-双键 (降低) |
| 2.55 | 反式环氧 (新峰) |
| 2.80 | 顺式环氧 (新峰) |

### 反应选择性

m-CPBA 环氧化同样表现出对 1,4-加成双键的优先反应性。

## FT-IR 特征

### 环氧基确认

| 波数 (cm⁻¹) | 归属 |
|-------------|------|
| 1260 | C-O-C 对称伸缩 |
| 801 | C-O-C 不对称伸缩 |

## m-CPBA 特点

### 与甲酸/H₂O₂对比

| 方面 | m-CPBA | 甲酸/H₂O₂ |
|------|--------|-----------|
| 反应速率 | 较快 | 需控制 |
| 副产物 | m-CBA | HCOOH + H₂O |
| 开环风险 | 低 | 略高 |
