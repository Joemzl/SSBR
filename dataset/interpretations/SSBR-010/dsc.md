## DSC 曲线解读

### 1. Tg 变化机理

OS2.9 的 Tg 升高 1.1℃ 的原因：

**氢键作用**:
- 羟基间形成分子间氢键
- 氢键约束链段运动
- Tg 升高程度与羟基含量正相关

```
~CH₂-CH-CH₂~ + ~CH₂-CH-CH₂~
      |               |
      S               S
      |               |
      CH₂             CH₂
      |               |
      CH₂             CH₂
      |               |
      O-H---O-H
      ↑ 氢键作用
```

### 2. Tg 与羟基含量关系

| 羟基含量 (mmol/100g) | Tg (℃) | Tg 变化 |
|---------------------|--------|--------|
| 0 | -26.1 | - |
| 24 | -25.0 | +1.1℃ |
| 64 | -21.3 | +4.8℃ |
| 83 | -17.7 | +8.4℃ |

**线性关系**: ΔTg ≈ 0.1 × [OH]

### 3. 低温性能评估

| 评估项目 | OS2.9 表现 |
|----------|-----------|
| Tg 绝对值 | -25.0℃（优异） |
| 与室温差距 | ~50℃（安全裕度大） |
| 冬季使用 | 完全满足 |
| 极寒环境 | 需要评估 |

### 4. 与轮胎性能关联

| 温度区间 | 性能相关性 | OS2.9 预期 |
|----------|-----------|-----------|
| Tg 附近 | 最大能量耗散 | -25℃ 区域 |
| 0℃ (抗湿滑) | tan δ 高有利 | 中等水平 |
| 60℃ (滚阻) | tan δ 低有利 | 中等水平 |

## 结论

1. **Tg = -25.0℃**: 比未改性 SSBR 升高 1.1℃
2. **氢键机理**: 羟基间氢键导致链运动受限
3. **优异低温性能**: Tg 远低于室温，满足轮胎应用
4. **线性相关**: Tg 升高与羟基含量呈正相关
