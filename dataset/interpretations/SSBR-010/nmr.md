## ¹H NMR 特征峰

### 主要化学位移

| 化学位移 (ppm) | 归属 | 强度变化 |
|---------------|------|----------|
| 4.9 | CH₂= (乙烯基) | 降低 ~3% |
| 5.3 | =CH- (乙烯基) | 降低 ~3% |
| 2.6 | -CH₂-S-CH₂- | **新峰** |
| 3.6 | -CH₂-O- | **新峰** |
| 6.5-7.2 | 芳香质子 | 不变 |

### 接枝反应验证

| 证据 | OS2.9 观察 |
|------|-----------|
| 乙烯基消耗 | 4.9 和 5.3 ppm 强度降低 |
| 硫醚键形成 | 2.6 ppm 新峰 |
| 羟乙基引入 | 3.6 ppm 新峰 |

## NMR 谱图解读

### 1. 硫醇-烯反应确认

反应方程式：
```
SSBR-CH=CH₂ + HS-CH₂-CH₂-OH → SSBR-CH₂-CH₂-S-CH₂-CH₂-OH
     ↓                              ↓           ↓
   4.9, 5.3 ppm                  2.6 ppm    3.6 ppm
   (信号降低)                    (新信号)    (新信号)
```

### 2. 接枝率计算

Zhang_2018 的计算方法：

$$R_g = \frac{I_{2.6,x}}{2 \times I_{4.9,0}} \times 100\%$$

| 参数 | 值 |
|------|-----|
| I₂.₆,ₓ (OS2.9 的 2.6 ppm 积分) | 相对值 |
| I₄.₉,₀ (未改性 SSBR 的 4.9 ppm 积分) | 基准 |
| **Rg (接枝率)** | **2.9%** |

### 3. 微观结构变化

| 结构单元 | 未改性 SSBR | OS2.9 | 变化 |
|----------|------------|-------|------|
| 苯乙烯 (mol%) | 与 wt% 相关 | 不变 | - |
| 乙烯基 (mol%) | 基准 | -2.9% | 被消耗 |
| 1,4-PB | 基准 | 不变 | - |
| 羟乙基硫醚 | 0 | 2.9% | 新引入 |

### 4. 峰归属详解

| 化学位移 | 质子类型 | 结构 |
|----------|---------|------|
| 2.6 ppm | -CH₂-**S**-CH₂- | 硫醚键连接的亚甲基 |
| 3.6 ppm | -CH₂-**O**H | 羟基相邻亚甲基 |

## FTIR 辅助分析

### 特征峰变化

| 波数 (cm⁻¹) | 归属 | OS2.9 变化 |
|-------------|------|-----------|
| 909 | =CH₂ 面外弯曲 | 强度降低 |
| 994 | =CH₂ 面外弯曲 | 强度降低 |
| 699 | 单取代苯（归一化） | 不变 |
| ~3400 | O-H 伸缩 | 可能出现宽峰 |

### 乙烯基消耗验证

FTIR 谱图显示：
- 909 cm⁻¹ 和 994 cm⁻¹ 峰强度随 ME 用量增加而降低
- 对于 OS2.9，降低幅度约 3%（与 NMR 一致）

## 官能化效率分析

### 反应参数

| 参数 | 设定值 |
|------|--------|
| ME/乙烯基摩尔比 | 0.03:1 |
| AIBN 用量 | 0.2 mol% (相对于乙烯基) |
| 反应温度 | 80℃ |
| 反应时间 | 2 h |

### 转化效率

| 计算 | 结果 |
|------|------|
| 理论最大接枝率 | 3% (受 ME 用量限制) |
| 实际接枝率 | 2.9% |
| **转化效率** | **~97%** |

## 分子量影响

| 参数 | 未改性 | OS2.9 | 变化 |
|------|--------|-------|------|
| Mn | 3.95×10⁵ | ~3.95×10⁵ | 无显著变化 |
| Mw/Mn | 1.15 | ~1.15 | 无显著变化 |

> 说明：硫醇-烯反应不引起主链断裂，分子量保持稳定

## 结论

1. **接枝率 2.9%**: 通过 NMR 定量分析确认
2. **高转化效率**: ~97% 的 ME 成功接枝
3. **结构完整性**: 分子量无显著变化
4. **官能团引入**: 成功引入羟基和硫醚键
