## 性能解读

### 1. 羟基化效应

OS2.9 的羟基含量为 24 mmol/100g：
- **较低的羟基密度** 限制了交联位点数量
- 部分丙烯酸酯可能只与单个羟基反应，形成悬挂链而非有效交联
- 交联效率相对较低

### 2. oxa-Michael 反应机理

```
R-OH + CH₂=CH-COOR' → R-O-CH₂-CH₂-COOR'
```

- 羟基在高温下活化
- 亲核进攻丙烯酸酯的 C=C 双键
- 形成醚键完成交联

### 3. 网络结构特点

| 特性 | OS2.9 |
|------|-------|
| 有效交联点 | 较少 |
| 悬挂链 | 可能较多 |
| 网络均匀性 | 中等 |
| 弱交联 (2C₂) | 较高 |

### 4. 与传统硫化对比

| 对比项 | oxa-Michael (OS2.9) | 传统硫化 |
|--------|--------------------|---------| 
| 助剂数量 | 1 种（丙烯酸酯） | 6+ 种 |
| 毒性 | 低 | 较高 |
| 硫化速度 | 适中 | 适中 |

## 关键发现

1. **羟基含量是关键**: 24 mmol/100g 的羟基含量相对较低
2. **交联效率受限**: 低羟基密度导致交联效率降低
3. **绿色环保**: oxa-Michael 交联避免了传统硫化的多种有毒助剂
4. **性能基础**: 为更高官能化程度样本提供对比基准
