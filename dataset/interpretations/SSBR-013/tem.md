## 填料分散机理分析

### 未改性 SSBR 的问题

| 问题 | 原因 |
|------|------|
| 极性不匹配 | SSBR 非极性，白炭黑高极性 |
| 氢键聚集 | 白炭黑表面硅羟基自聚 |
| 界面弱 | 橡胶-填料相互作用弱 |

### 填料网络类型

```
未改性体系：填料-填料主导

    SiO₂ ← 氢键 → SiO₂
      ↑            ↑
    氢键        氢键
      ↓            ↓
    SiO₂ ← 氢键 → SiO₂
    
    橡胶基体被填料网络排斥
```

### 改性后的变化

```
改性体系：填料-橡胶-填料

    SiO₂ ← 羧基...氢键 → SSBR-COOH
      ↑                    ↑
    氢键            化学/物理键
      ↓                    ↓
    SiO₂ ← 羧基...氢键 → SSBR-COOH
    
    极性改性橡胶作为桥梁
```

## 与轮胎性能关联

### 分散-性能关系

| 性能 | 分散差的影响 |
|------|-------------|
| 抗湿滑 | tan δ (0℃) 较低 |
| 滚动阻力 | tan δ (60℃) 较高 |
| 耐磨性 | 局部应力集中，耐磨差 |
| 撕裂强度 | 团聚体导致弱点 |

## 结论

1. **明显团聚**: 未改性 SSBR 中白炭黑严重团聚
2. **分散最差**: 系列中分散质量最低
3. **界面弱**: 橡胶-填料相互作用最弱
4. **改进空间大**: 官能化可显著改善分散
