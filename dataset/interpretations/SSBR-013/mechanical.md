## 性能解读

### 1. 填料分散问题

未官能化 SSBR 与白炭黑的**相容性差**：

| 问题 | 描述 |
|------|------|
| 极性差异 | SSBR 非极性，白炭黑高极性 |
| 填料团聚 | 白炭黑倾向于自聚集 |
| 界面相互作用 | 弱 |
| 分散质量 | 较差 |

### 2. 硅烷偶联剂作用

Si-69 改善填料-橡胶界面：
- 与白炭黑表面硅羟基反应
- 但对 SSBR 本体极性改善有限
- 仍存在分散不均匀问题

### 3. 硫化特性分析

| 观察 | 解释 |
|------|------|
| 较长 tc₉₀ (29.3 min) | 白炭黑吸附促进剂和 ZnO |
| 硫化迟延效应 | 白炭黑表面硅羟基的影响 |
| 扭矩差 26.77 dN·m | 交联密度参考基准 |

### 4. 结合胶分析

结合胶 52.6% 反映橡胶-填料相互作用强度：
- 结合胶是吸附在填料表面的橡胶层
- 厚度约几纳米
- 相互作用越强，结合胶含量越高

## 填料分散评估

### L 值（分散性指标）

$$L = \eta_r - \mu_r$$

其中：
- $\eta_r = M_{L,filled}/M_{L,gum}$
- $\mu_r = M_{H,filled}/M_{H,gum}$

L 值越低，分散性越好。

1. **分散性基准**: 未官能化 SSBR 填料分散质量参考
