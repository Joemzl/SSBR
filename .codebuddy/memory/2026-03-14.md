### 新的工作流程

1. 用户使用豆包/Gemini 解析 PDF，按 `other/解析数据的提示词.txt` 格式输出
2. 运行 `python scripts/import_metadata.py --file data.md` 导入 Excel
3. 运行 `python scripts/init_new_sample.py --sample-id SSBR-XXX` 初始化目录
4. 使用 Skills 生成解读文档
