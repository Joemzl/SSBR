## RAG 检索性能优化 (2026-03-19)

### 问题
- 原实现每次查询需要向量化所有 82 个文档
- 查询延迟 25-30 秒，严重影响用户体验

### 解决方案
1. **向量缓存机制** - 预计算并持久化文档向量到 `.cache/vector_cache.json`
2. **批量 Embedding API** - 使用 `embed_batch()` 一次调用替代逐条调用
3. **增量更新** - 基于文件哈希检测变更，只更新需要的文档
4. **Web Demo 预加载** - 启动时自动加载缓存

### 新增文件
- `scripts/utils/vector_cache.py` - 向量缓存模块
- `scripts/build_vector_cache.py` - 缓存构建脚本

### 性能提升
| 指标 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| 单次查询延迟 | 25-30 秒 | **1-2 秒** | **15-20x** |
| 缓存构建时间 | - | 12.7 秒 | - |
| 缓存文件大小 | - | 3.8 MB | - |

### 使用方式
```bash
# 构建/更新向量缓存
python scripts/build_vector_cache.py

# 查看缓存状态
python scripts/build_vector_cache.py --stats

# 强制重建缓存
python scripts/build_vector_cache.py --force
```
