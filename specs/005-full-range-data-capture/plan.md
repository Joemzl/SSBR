## 三、Prompt 模板设计

### 3.1 应力-应变曲线全范围估读 Prompt

```markdown
## 任务：从应力-应变曲线图中估读全范围数据

### 图像信息
[附上曲线图图像]

### 目标曲线识别
请识别图中 **样本 {sample_name}** 对应的曲线（参考图例）。

### Step 1: 坐标系识别
请识别并输出以下信息（JSON 格式）：
```json
{
  "x_axis": {
    "label": "应变",
    "unit": "%", 
    "min": 0,
    "max": 500,
    "scale": "linear"
  },
  "y_axis": {
    "label": "应力",
    "unit": "MPa",
    "min": 0,
    "max": 25,
    "scale": "linear"
  }
}
```

### Step 2: 多点数据估读
请估读目标曲线在以下应变值处的应力值：

| 应变 (%) | 应力 (MPa) | 置信度 (1-5) |
|----------|------------|--------------|
| 0        |            |              |
| 25       |            |              |
| 50       |            |              |
| 75       |            |              |
| 100      |            |              |
| 125      |            |              |
| 150      |            |              |
| 175      |            |              |
| 200      |            |              |
| 250      |            |              |
| 300      |            |              |
| 350      |            |              |
| 400      |            |              |
| [断裂应变] |           |              |

**置信度说明**：
- 5: 曲线清晰，可精确读取
- 4: 曲线较清晰，误差 <5%
- 3: 曲线可辨识，误差 <10%
- 2: 曲线模糊，误差 10-20%
- 1: 高度不确定，仅供参考

### Step 3: 断裂点信息
- 断裂应变: _____%
- 拉伸强度: _____ MPa

### Step 4: 曲线特征描述
- 初始斜率（0-50% 应变区间）：_____ MPa/%
- 是否存在明显屈服平台：是/否
- 硬化行为描述：[轻微/中等/显著]

### 输出格式
最终请以 YAML 格式输出：
```yaml
curve_data:
  source_type: "L3-AI估读"
  confidence: [平均置信度, 1-5]
  data_points:
    - [应变, 应力]
    - ...
  break_point:
    strain: 
    stress:
  curve_features:
    initial_modulus:
    yield_observed: 
    hardening_level:
```
```
