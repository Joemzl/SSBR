# 002-rag-recommendation-system 需求文档

## 1. 项目背景

### 1.1 现状

当前 SSBR 官能化知识库（`001-ssbr-knowledge-recommender`）已完成：

- Excel 数据模型定义（样本基础信息、表征图注、力学/热学数值）
- 7 个专业解读 Skills（NMR、TEM、应力-应变、Payne、DMA、DSC、力学调度）
- 1 个推荐 Skill（`ssbr-recommender`）

### 1.2 问题

现有推荐系统基于**精确匹配/范围筛选**，存在以下局限：

1. **无法理解用户意图**：用户说"我要改善白炭黑分散性"，系统无法将其关联到 Payne 效应、TEM 分散性等指标
2. **数据稀疏**：仅 17 条样本数据，精确匹配几乎找不到完全符合的案例
3. **缺乏推导能力**：系统只能返回筛选结果，无法基于相似案例推导出新方案
4. **结构化数据的语义缺失**：Excel 中的数值（如 `tanδ=0.08`）缺乏上下文解释，LLM 无法理解其物理意义
5. **扩展性差**：每次新增性能指标（如 Payne、DMA 数据）都需要修改 Excel 表结构

### 1.3 目标

构建基于 RAG（Retrieval-Augmented Generation）的智能推荐系统，实现：

- 用户以自然语言描述需求
- 系统通过语义相似度检索最相关的历史案例
- LLM 基于检索到的案例，推导出个性化的官能化方案推荐
- **数据结构可灵活扩展，新增性能指标无需修改 Excel**

---

## 2. 核心架构设计

### 2.1 数据分层架构

采用「元数据 + 解读文档」分离的架构，实现数据的灵活扩展：

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 1: 元数据层（Excel 数据.xlsx）                        │
│  只存储固定不变的基础信息，不随解读扩展而修改                  │
│  - A-H: 样本基础信息（ID、官能化试剂、官能团等）              │
│  - I-L: 表征图注（核磁、TEM、核心力学图谱、DSC）             │
│  - M-O: 文献来源（引文、DOI、DOI_SI）                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Layer 2: 解读数据层（/interpretations/{样本ID}/*.md）       │
│  存储所有解读结果，包括结构化数值和自然语言描述                │
│  - nmr.md: 核磁解读（含YAML数值 + 文字描述）                 │
│  - tem.md: TEM解读（含YAML数值 + 文字描述）                  │
│  - mechanical.md: 力学解读（含YAML数值 + 文字描述）          │
│  - dsc.md: DSC解读（含YAML数值 + 文字描述）                  │
│  【可无限扩展，新增类型只需新建文件】                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Layer 3: 检索索引层（/interpretations/{样本ID}/summary.md） │
│  综合所有解读生成的自然语言摘要，用于 RAG 语义检索            │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 架构优势

| 维度 | 旧方案（Excel存数值） | 新方案（文档存数值） |
|------|---------------------|---------------------|
| **扩展性** | ❌ 新增指标要加列 | ✅ 新增指标只改文档 |
| **数据一致性** | ⚠️ 两处存储要同步 | ✅ 单一数据源 |
| **语义理解** | ❌ 纯数值无上下文 | ✅ 数值+解释+机理 |
| **Git 友好** | ❌ Excel 难以 diff | ✅ Markdown 友好 |
| **RAG 适配** | ⚠️ 需额外转换 | ✅ 原生支持 |

## 3. 核心需求

### 3.1 数据层需求

#### 3.1.1 Excel 瘦身（只保留元数据）

**保留的列（A-O）**：

| 列 | 字段名 | 说明 | 变化 |
|----|--------|------|------|
| A | 样本ID | 唯一标识符 | 不变 |
| B | 应用场景 | 目标应用领域 | 不变 |
| C | 官能化试剂名称 | 试剂全称 | 不变 |
| D | 试剂整体 SMILES | 分子结构 | 不变 |
| E | 核心官能团 SMILES | 官能团结构 | 不变 |
| F | 核心官能团名称 | 中文名称 | 不变 |
| G | 核心官能团化学式 | 化学式 | 不变 |
| H | 官能化程度 (wt%) | 接枝程度 | 不变 |
| I | 核磁谱图 | 图注引用 | 不变 |
| J | 微相分离图片表征 | TEM 图注 | 不变 |
| K | 核心力学图谱 | 力学图注 | 不变 |
| L | DSC 谱图 | DSC 图注 | 不变 |
| M | 引文 | 完整引文 | 不变 |
| N | DOI | 文献 DOI | 不变 |
| O | DOI_SI | SI 补充材料 DOI | 不变 |

**移除的列（P-W）**：

原 P-W 列的力学/热学数值数据将迁移到解读文档中存储。

#### 3.1.2 解读文档存储结构

```
/dataset/interpretations/
├── SSBR-001/
│   ├── nmr.md           # 核磁解读
│   ├── tem.md           # TEM 解读
│   ├── mechanical.md    # 力学图谱解读（应力-应变/Payne/DMA）
│   ├── dsc.md           # DSC 解读
│   └── summary.md       # 综合档案（必需，用于 RAG 检索）
├── SSBR-002/
│   └── ...
└── ...
```

#### 3.1.3 解读文档格式规范

每个解读文档采用 **YAML front matter + Markdown 正文** 格式：

**示例：mechanical.md**

```markdown
---
sample_id: SSBR-001
type: mechanical
skill_used: ssbr-stress-strain-interpretation
source_figure: Figure 4
source_doi: 10.1039/c9ra02783a
created_at: 2026-03-04

# 结构化数值（YAML格式，可被程序解析）
data:
  # 应力-应变数据
  stress_100:
    value: 1.5
    unit: MPa
    source: "SI Table S5"
  stress_300:
    value: 9.0
    unit: MPa
    source: "SI Table S5"
  tensile_strength:
    value: 15.0
    unit: MPa
    source: "SI Table S5"
  elongation:
    value: 452
    unit: "%"
    source: "SI Table S5"
  
  # Payne效应数据（如适用）
  delta_g_prime:
    value: 850
    unit: kPa
    source: "Figure 5"
  delta_g_prime_reduction:
    value: 45
    unit: "%"
    source: "calculated"
  
  # DMA数据（如适用）
  tan_delta_0c:
    value: 0.45
    unit: "-"
    source: "SI Table S6"
  tan_delta_60c:
    value: 0.08
    unit: "-"
    source: "SI Table S6"
---

# 力学性能解读：SSBR-001

## 一、静态力学性能（应力-应变曲线）

### 核心发现

1. **模量增强效果**
   - 100%定伸应力：1.5 MPa（空白样 1.0 MPa），提升 50%
   - 300%定伸应力：9.0 MPa（空白样 6.7 MPa），提升 34%
   - 机理：三乙氧基硅烷基与白炭黑表面-OH形成共价键，增强界面结合

2. **强度与韧性平衡**
   - 拉伸强度：15.0 MPa，保持在优秀水平
   - 断裂伸长率：452%，较空白样（520%）下降 13%
   - 评价：在增强模量的同时保持了良好的韧性

### 曲线特征
- 初始斜率高于空白组，定伸模量更大
- 无明显屈服平台
- 断裂点延伸率略有下降

## 二、动态力学性能（Payne效应）

### 核心发现

1. **填料网络强度降低**
   - ΔG' = 850 kPa（空白样 1550 kPa），下降 45%
   - 表明填料团聚程度显著降低，分散性改善

2. **橡胶-填料界面增强**
   - 官能团与白炭黑形成化学键合
   - 有效抑制填料二次团聚

## 三、动态力学性能（DMA温度扫描）

### 核心发现

1. **滚动阻力降低**
   - 60℃ tanδ = 0.08（空白样 0.12），降低 33%
   - 预示轮胎滚动阻力显著降低

2. **湿地抓地力保持**
   - 0℃ tanδ = 0.45（空白样 0.42），略有提升
   - 湿地抓地力不受负面影响

3. **性能平衡因子**
   - 0℃tanδ/60℃tanδ = 5.6（空白样 3.5）
   - 综合性能显著优于空白样

## 四、文献原文结论

"The functionalized SSBR with triethoxysilane groups showed significantly improved 
silica dispersion and reduced rolling resistance while maintaining wet grip performance."
```

#### 3.1.4 summary.md 规范

每个样本必须生成一个 `summary.md` 综合档案，**专门用于 RAG 语义检索**。

**关键要求**：
- 必须是**自然语言描述**，而非纯数值罗列
- 涵盖所有已完成的解读内容
- 突出该方案的**核心价值和适用场景**

**示例：summary.md**

```markdown
---
sample_id: SSBR-001
type: summary
created_at: 2026-03-04
interpretations_included:
  - mechanical
  - dsc
---

# SSBR-001 综合档案

## 一句话总结

采用三乙氧基硅烷基官能化的 SSBR 方案，可显著改善白炭黑分散性，实现"低滚阻-高抓地"的性能平衡，适用于绿色轮胎胎面。

## 官能化信息

- **试剂**：3-氨丙基三乙氧基硅烷 (APTES)
- **核心官能团**：三乙氧基硅烷基 (-Si(OC₂H₅)₃)
- **官能化程度**：3.6 wt%
- **改性方法**：巯基-烯点击化学

## 核心性能特点

### 白炭黑分散性 【显著改善】
官能化后白炭黑在橡胶基体中的分散性显著提升。Payne效应测试显示 ΔG' 下降 45%，表明填料团聚程度大幅降低。机理上，硅烷基与白炭黑表面羟基形成共价键，提高了橡胶-填料界面相容性，有效抑制填料二次团聚。

### 动态力学性能 【滚阻降低、抓地力保持】
DMA 温度扫描结果显示：60℃ tanδ 从 0.12 降至 0.08，预示滚动阻力降低约 33%；0℃ tanδ 保持在 0.45，湿地抓地力不受负面影响。性能平衡因子从 3.5 提升至 5.6，综合性能显著优于未改性样品。

### 静态力学性能 【模量提升、韧性略降】
100%定伸应力提升 50%（1.5 vs 1.0 MPa），300%定伸应力提升 34%，拉伸强度保持在 15 MPa 的优秀水平。断裂伸长率从 520% 降至 452%，下降约 13%，韧性略有牺牲但仍满足应用需求。

### 热学性能
玻璃化转变温度 Tg = -9℃，处于轮胎胎面胶的适用区间（-50℃ ~ -20℃）。

## 适用场景

✅ **绿色轮胎胎面**：追求低滚阻与高抓地力的平衡
✅ **需要改善白炭黑分散性的配方体系**
✅ **对模量有较高要求的应用**

⚠️ **注意**：对极限韧性要求较高的场景需谨慎评估

## 文献来源

- **DOI**: 10.1039/c9ra02783a
- **引文**: [完整引文信息]
```

### 3.2 Skills 层需求

#### 3.2.1 新增 Skill：`ssbr-summary-generator`

**功能**：读取指定样本的所有数据（Excel 元数据 + 已有解读文档），自动生成 `summary.md` 综合档案。

**输入**：
```
请为样本 SSBR-001 生成综合档案
```

**处理流程**：
1. 从 Excel 读取 A-O 列的元数据
2. 检索 `/interpretations/SSBR-001/` 下已存在的解读文档
3. 提取各解读文档的 YAML 数值和核心发现
4. 综合生成自然语言描述的 summary.md

**输出**：
- 在 `/dataset/interpretations/SSBR-001/` 下生成 `summary.md`

#### 3.2.2 现有 Skills 调整

| Skill | 调整内容 |
|-------|---------|
| `ssbr-stress-strain-interpretation` | 输出格式改为 YAML+Markdown，保存到 `mechanical.md` |
| `ssbr-payne-interpretation` | 输出格式改为 YAML+Markdown，追加到 `mechanical.md` |
| `ssbr-dma-interpretation` | 输出格式改为 YAML+Markdown，追加到 `mechanical.md` |
| `ssbr-dsc-interpretation` | 输出格式改为 YAML+Markdown，保存到 `dsc.md` |
| `ssbr-nmr-interpretation` | 输出格式改为 YAML+Markdown，保存到 `nmr.md` |
| `ssbr-tem-interpretation` | 输出格式改为 YAML+Markdown，保存到 `tem.md` |
| `ssbr-mechanical-interpretation` | 调度层，根据 K 列内容调用对应子 Skill |

### 3.3 向量存储层需求

#### 3.3.1 向量化目标

对每个样本的 `summary.md` 进行向量化（Embedding），生成高维向量表示。

#### 3.3.2 技术选型

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **Chroma**（Python 本地） | 轻量、易集成、无需服务 | 依赖 Python | 快速原型 |
| **SQLite + sqlite-vec** | 与现有结构兼容 | 需编译扩展 | 长期方案 |
| **纯文件 + 实时计算** | 最简单、无额外依赖 | 检索慢（17条可接受） | MVP 验证 |

**MVP 建议**：17 条数据量极小，可先采用"纯文件 + 实时调用 Embedding API"方案验证效果，后续再优化。

#### 3.3.3 Embedding 模型

推荐使用 OpenAI `text-embedding-3-small`（1536 维），或其他兼容模型。

### 3.4 推荐流程需求

#### 3.4.1 整体流程

```
用户输入（自然语言需求）
        │
        ▼
┌───────────────────────────────────────┐
│  Step 1: 查询向量化                    │
│  将用户输入转换为 Embedding 向量        │
└───────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────┐
│  Step 2: 语义检索                      │
│  计算用户向量与所有 summary.md 向量的   │
│  余弦相似度，返回 Top-K（默认 K=3）    │
└───────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────┐
│  Step 3: 上下文构建                    │
│  将 Top-K 样本的 summary.md 全文       │
│  作为 LLM 的上下文                     │
└───────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────┐
│  Step 4: 推荐生成                      │
│  LLM 基于上下文 + 用户需求，生成       │
│  个性化的官能化方案推荐                │
└───────────────────────────────────────┘
        │
        ▼
推荐输出（含推荐方案 + 参考案例 + 理由）
```

#### 3.4.2 推荐输出格式

```markdown
## 推荐方案

**预期效果**：
- 白炭黑分散性：ΔG' 预计下降 30-50%

- 湿地抓地力：0℃ tanδ 基本保持

**参考案例**：

**注意事项**：
- 断裂伸长率可能下降 10-15%

```

#### 3.4.3 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 用户需求过于模糊 | 引导用户明确：应用场景、关注的性能指标 |
| 无相似案例（相似度 < 0.5） | 提示"知识库中无高度相关案例"，给出最接近的参考 |
| 用户需求超出知识库范围 | 明确告知"本知识库专注于巯基-烯点击化学改性"，拒绝编造 |

## 4. 工作流定义

### 4.1 数据迁移工作流（一次性）

```
对现有 Excel 数据：
│
├─ Step 1: 备份当前 Excel
│   └─ 保存 数据.xlsx 副本
│
├─ Step 2: 为每个样本创建解读文档目录
│   └─ /interpretations/SSBR-001/ ~ /SSBR-017/
│
├─ Step 3: 迁移 P-W 列数据到解读文档
│   ├─ 将力学数据（P-U）写入 mechanical.md 的 YAML
│   └─ 将热学数据（V-W）写入 dsc.md 的 YAML
│
├─ Step 4: 删除 Excel 的 P-W 列
│   └─ Excel 只保留 A-O 列
│
└─ Step 5: 为每个样本生成 summary.md
    └─ 调用 ssbr-summary-generator
```

### 4.2 新样本录入工作流

```
用户提供新文献/新样本
│
├─ Step 1: 录入元数据
│   └─ 在 Excel 中填写 A-O 列
│
├─ Step 2: 创建样本目录
│   └─ /interpretations/{新样本ID}/
│
├─ Step 3: 表征解读
│   ├─ 调用相应的解读 Skills
│   └─ 自动保存到对应的 .md 文件
│
├─ Step 4: 生成综合档案
│   └─ 调用 ssbr-summary-generator
│
└─ Step 5: 更新向量索引
    └─ 对新 summary.md 进行向量化并存储
```

### 4.3 推荐查询工作流

```
用户输入自然语言需求
│
├─ Step 1: 需求理解（可选）
│   └─ 若需求模糊，引导用户补充信息
│
├─ Step 2: 语义检索
│   ├─ 向量化用户查询
│   └─ 检索 Top-K 相似样本
│
├─ Step 3: 上下文增强生成
│   ├─ 构建 Prompt（用户需求 + Top-K summary）
│   └─ LLM 生成推荐
│
└─ Step 4: 输出推荐结果
    └─ 包含：推荐方案 + 参考案例 + 预期效果 + 注意事项
```

## 5. 非功能性需求

### 5.1 性能要求

- 单次推荐查询响应时间 < 30 秒（含 Embedding + LLM 生成）
- 17 条样本全量向量化 < 5 分钟

### 5.2 可维护性

- **新增样本**：无需修改代码，只需运行工作流
- **新增表征类型**：只需新建 Skill + 更新 summary 模板
- **新增性能指标**：只需在解读文档的 YAML 中添加字段，无需改 Excel

### 5.3 科研合规性

- 推荐结果必须标注文献来源
- 禁止编造知识库中不存在的数据
- 对于估读/推导的数据，必须明确标注

## 9. 附录

### 9.1 与 001-ssbr-knowledge-recommender 的关系

本 Spec（002）是对 001 的**架构升级**，主要变更：

| 模块 | 001 设计 | 002 改进 |
|------|---------|---------|
| 数据存储 | Excel 列存储所有数值 | Excel 只存元数据，数值存解读文档 |
| 推荐方式 | 精确/范围匹配 | RAG 语义检索 |
| 扩展性 | 新增指标要加列 | 新增指标只改文档 |
| 数据来源 | 分散在多处 | 单一数据源（解读文档） |

- 解读文档模板：`/dataset/interpretations/TEMPLATE.md`
- 数据模型定义：`/specs/001-ssbr-knowledge-recommender/data-model.md`（需同步更新）
